### 二、团队协同守则

1. **各自独立，互不干扰**：
   * **Ben** 请在 `fpga_ben/` 内自由开展所有探索（包括但不限于算法原型、Verilog 硬件设计、仿真测试及技术文档）。
   * **Spark** 在 `fpga_spark/` 内自主推进软硬件全流程设计。
   * 严禁将各自生成的文件或测试脚本放入对方的文件夹内，禁止直接修改对方目录中的文件。
2. **保持自包含与自闭环**：
   * 各自目录下的工程文件（如 Gowin EDA `.gprj`）、Python 脚本、Verilog include 等相对路径均需在自身目录下相对定位，确保独立编译与运行不报错。
3. **后续阶段规划**：
   * 在各自独立探索并跑通 demo / 原型后，团队将针对两套方案的音色质量、资源占用、延迟指标进行联合评审，择优融合出最终的竞赛作品。
