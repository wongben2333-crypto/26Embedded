# 2026年全国大学生嵌入式芯片与系统设计竞赛（FPGA创新赛道 - 高云半导体）
## 实时多音色合成电子乐器引擎

本项目由团队协作开发，为保证硬件与算法开发互不干扰，项目采用双独立工作区物理隔离架构：

```text
├── fpga_spark/       # 【硬件工作区 - Spark】Tang Mega 60K 纯硬件工程与验证
│   ├── fpga_synthesizer.gprj # 高云云源软件 (Gowin EDA) 完整硬件工程
│   ├── rtl/                  # 纯硬件 Verilog 源代码 (DDS波表/ADSR/KS拨弦/钢琴/混音/I2S)
│   ├── constraints/          # Tang Mega 60K 物理引脚约束 (tang_mega_60k_pins.cst)
│   ├── sim/                  # 硬件专用测试激励与定点化行为验证
│   ├── tools/                # 波表 HEX 生成工具
│   ├── 原始音频/             # 原曲试听音频
│   └── *.wav                 # 纯硬件模型生成的高保真演示音频
│
└── fpga_ben/         # 【算法工作区 - Ben】Python 黄金参考模型与赛题材料
    ├── sim/                  # Python 算法黄金参考模型 (synthsim) 及测试脚本
    ├── 题目/                 # 赛题逐条精解、选型建议与外设准备清单
    ├── 选题/                 # 2026 嵌赛各赛道官方指南 PDF 资料
    └── 原题目-高云半导体赛道选题指南（2026）.md
```

### 开发协同守则
1. `fpga_spark/` 与 `fpga_ben/` 各自自闭环，所有相对路径在各自文件夹内部索引，互不影响。
2. 硬件开发与综合请直接使用 `fpga_spark/` 内的高云工程文件与源码。
