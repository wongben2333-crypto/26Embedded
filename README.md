## 一、项目概述与核心指标

本项目针对专业电子乐器与嵌入式合成引擎对**超低延时、高复音数与物理表现力**的极致需求，在国产高云 Arora-V 系列 138K FPGA 上设计并实现了**全纯硬件实时数字声音合成系统**。系统完全脱离软核处理器（无 RISC-V、无 ARM）与外部存储器（无 SD 卡、无预录 PCM/WAV 样本），所有声学运算、包络调制、人机交互与大屏显示均由硬件流水线单周期并行执行。

### 核心技术指标一览

| 指标项 | 赛题指标门限 | 本工程实测表现 | 评测结论 |
| :--- | :---: | :---: | :---: |
| **复音能力** | $\ge 16$ 路 | **32 路独立物理 DDS 振荡器** | 超额 100% 达成 |
| **端到端控制发声延迟** | $\le 5.00	ext{ ms}$ | **.01	ext{ ms}$**（纯硬件合成仅 	ext{ ns}$） | 优于指标 59.8% |
| **音频采样规格** | $\ge 44.1	ext{ kHz}$ / 16-Bit | **.65625	ext{ kHz}$ / 16-Bit 双声道** | 广播级高保真 |
| **测试模式独立谱峰** | 数量确切、无杂散 | **32 / 32 谱峰全部检出**，最大误差 .70	ext{ Hz}$ | PASS (Exit 0) |
| **合成真实性审查** | 严禁播放预录音频 | **纯 RTL 数学逻辑生成**，工程无音频 ROM | 审查合规 |
| **FPGA 芯片资源占用** | 资源可控 | 逻辑 **23.25%**、BSRAM **32.94%**、DSP **35.56%** | 时序完全收敛 |

## 二、团队成员分工

本项目由三位队员协同研发完成，分工涵盖从前期算法规划、底层纯硬件逻辑攻坚，到自研外设硬件制造与系统整机联调全链路：

* **Ben（系统架构与前期规划）**：
  * 赛题技术指标与评审要点深入拆解，制定纯硬件实时多乐器合成引擎方案；
  * 音频算法数学建模与初始原型仿真（Python/MATLAB），确定 32 复音 TDM 时分复用混音架构；
  * 负责前期器件选型（Tang Mega 138K、PT8211、GT911、VB22B ToF）与可行性论证报告。
* **Hank（纯硬件 RTL 核心算法与时序工程）**：
  * 主导核心 RTL 数字逻辑设计（32路独立 DDS 振荡器、自适应 ADSR 物理阻尼包络、吉他/小提琴箱体共振效果器）；
  * 构建 ModelSim 严密时序仿真用例（因果链、按键消抖边界、I2S 差分时序、TDM 混音）；
  * 撰写技术报告与竞赛申报材料，把关抗 AI 规则与学术严谨性。
* **Spark（大屏交互、自研硬件打样与系统联调）**：
  * 研发 7 寸 800×480 LCD（SSD1963）与 GT911 电容触摸屏纯硬件驱动控制器与 4 页面 GUI 引擎；
  * 完成自研主板与屏幕转接板 PCB 原理图绘制、Layout 布局布线、打样焊接与两件式外壳 3D 打印；
  * 开发自动化固化烧录脚本、硬件显存回读工具与 32 谱峰自动化 FFT 取证系统。

## 四、核心硬件规格与特性

### 1. 三大多模态乐器音色矩阵
* 🎹 **施坦威九尺大钢琴（Grand Piano）**：
  * 输入通道：板载 13 物理按键（C4 ~ C5 全八度白键+黑键）；
  * 物理建模：弦槌敲击毛毡力学响应，多谐波泛音衰减包络。
* 🎸 **全单原声木吉他（Acoustic Guitar）**：
  * 输入通道：6 路光电对射管拨弦感应阵列；
  * 物理建模：尼龙弦振动动力学，板面共鸣箱体滤波模拟。
* 🎻 **高保真抒情小提琴（Solo Violin）**：
  * 输入通道：双路 ToF 激光红外连续测距传感器（总线 A+B 空间感知手势）；
  * 物理建模：亥姆霍兹粘滑锯齿波（Helmholtz Motion）无级连续滑音与揉弦。

### 2. 7寸 800×480 仪表台多功能视效
* **Page 0 演奏界面**：3.00 秒连续时域示波器、立体声峰值电平计、动态琴键响应指示；
* **Page 1 示波界面**：时域音频示波器、128×128 矢量双通道李萨如相位轨迹仪、32频段对数 FFT 实时频谱分析柱状图；
* **Page 2 谱峰界面**：赛题测试模式专用取证仪表台，32 路离散谱峰检测指示灯实时全部点亮；
* **Page 3 曲目界面**：0~100% 满幅平滑滚动时间进度条、多声部滚动乐谱瀑布流、实时伴奏音频示波器。

## 五、快速复现与操作指南

### 1. 外部 SPI Flash 固化烧录（开箱即用）
开发板通过 Type-C 数据线连接电脑，运行以下脚本即可将预编译的已验证位流固化至板载 Winbond 64MB SPI NOR Flash，实现掉电不丢失、冷启动上电自运行：
`powershell
python flash_lcd_j14.py
`
> 注：脚本自动调用高云 programmer_cli.exe，采用 GAO-Bridge 协议（Op 68）执行扇区擦除、高速写入与 CRC 校验，耗时约 85 秒。

### 2. 一键全流程综合与布局布线 (P&R)
如需从 Verilog 源码重新生成位流，运行一键构建脚本即可自动化完成综合、引脚匹配、时钟树综合与位流打包：
`powershell
python build_j14.py
`

### 3. 赛题 32 谱峰自动化 FFT 取证验证
验证数字音频合成通路纯硬件实时生成性，运行独立的 Python FFT 判定工具：
`powershell
python tools/verify/check_peaks.py --file docs/evidence/tone_samples_snap.txt --format samples --fs 97656.25 --count 32 --start 200 --step 200
`
* **期望输出**：检出率 32/32 (100%)，未预期杂散峰为 0，最大误差 0.70 Hz，返回码 0 (PASS)。

### 4. 7寸液晶屏实时硬件显存回读截屏
通过板载 USB-UART 接口实时截取当前 800×480 真实显存图像：
`powershell
python tools/screenshot_lcd.py
`

### 5. 物理硬件按键响应实时监测终端
连接开发板并启动交互终端，实时观察物理按键、编码器或触控屏幕的触发事件与毫秒级延迟数据：
`powershell
python tools/live_hw_monitor.py
`
