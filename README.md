# 基于 FPGA 的实时多音色合成电子乐器引擎「芯弦和鸣」

> **2026 全国大学生嵌入式芯片与系统设计竞赛 · FPGA 创新设计赛道 · 高云半导体 · 选题二**  
> **目标器件**：高云 Arora-V `GW5AST-LV138PG484AC1/I0`（`GW5AST-138C`，Sipeed Tang Mega 138K Dock）  
> **交付位流**：`MODE=3` 整机模式 · 50 MHz 单时钟域 · 纯 HDL · 无 CPU/PCM

## 1. 项目概述

本项目的目标是在单颗高云 Arora-V 138K FPGA 上，用纯 HDL 构建一套**不依赖 CPU、不播放预录 PCM** 的实时多音色电子乐器。系统把 13 键硅胶轻触键盘、6 路光电拨弦、双路 ToF 手势与 7 寸电容触控接入统一单拍事件总线，由 **TDM32 引擎**在 97,656.25 Hz 采样网格上逐样本合成 **32 声部 × 6 泛音 = 192 路独立振荡器**，再经 8 模块硬件效果链与 PT8211 I2S DAC 输出。整机物理输入到模拟输出实测 **2 ms**，芯片内部 note event 到数字首样本上界 **20.5 µs**，TDM32 流水内部 **3.85 µs**。

全并行 8 声部 × 6 泛音 = 48 路引擎已验证并保留为低延迟对比基线；为达到 32 复音 192 路，交付位流采用 512 拍周期内 192 拍微时隙的 TDM32 架构：单套 DSP 与 BSRAM 状态表分时服务 32 个声部，避免宽加法树与高扇出分配器带来的布线瓶颈。音色统一为**钢琴 / 吉他 / 小提琴** 3 种，均由真实乐器录音频域反演得到泛音权重与琴体共振参数，在零音频样本 ROM 的前提下完成参数化重构。

## 2. 主要特性

- **192 路独立振荡器**：32 声部 × 6 泛音，每路独立 32 位相位累加器、独立频率字、独立 Q32 包络。
- **3 种音色**：钢琴、吉他、小提琴；42 行核心泛音表（TDM32 展开 120 行）+ 非谐性拉伸 + 琴体共振 + 击弦/拨弦瞬态。
- **超低确定性延迟**：整机 2 ms；芯片内部 512 相位全枚举上界 20.5 µs；TDM32 流水 3.85 µs。
- **8 模块硬件效果链**：4 路并联梳状 + 2 级全通 Freeverb、LFO 合唱、环形回声、过载/箱体模拟、双斜率软膝削波。
- **7 寸 800×480 仪器 UI**：3.0 秒双缓冲示波器、32 通道硬件 FFT、X-Y 李萨如、四页触控界面、虚拟琴键演奏。
- **必备取证模式**：`MODE=2` 输出 200 Hz～6,400 Hz 共 32 路等间隔独立谱峰；192 路由 RTL 状态阵列（`mem_ph` / `mem_inc` / `mem_env`）证明。
- **自研物理交互**：13 键硅胶轻触按钮 + 6 路 12V 光电 + 双路 ToF（A 主用/B 热备）+ 7 寸电容触控；4 路 EC11 仅预留，音量由触屏/上位机 CC7 控制。
- **纯硬件合规**：音频链路全部由 FPGA 逐样本生成；无软核/硬核 CPU 参与合成；无预录 PCM、无整段录音触发。

## 3. 系统架构

```text
13 键硅胶轻触 ─┐
6 路光电拨弦   ─┤
双路 ToF A/B   ─┼─► 单拍事件总线 ─► 一热声部分配（0 clk）
7 寸电容触控   ─┤                         │
UART / MIDI    ─┤                         ▼
Song ROM（4 首）┘              TDM32：32 声部 × 6 泛音 = 192 振荡器
                                          │
                         8 模块硬件效果链（Freeverb / Chorus / Echo / Cab）
                                          │
                           PT8211 I2S @ 97,656.25 Hz → 耳机 / 2×3W 功放
                                          │
                           7 寸 800×480 UI（示波 / FFT / 李萨如 / 曲目）
```

- 全芯片单一 50 MHz 同步时钟；`sample_tick = 50 MHz ÷ 512 = 97,656.25 Hz`。
- 音符事件采用单拍脉冲 + 数据保持，无 ACK 握手；装载状态机固定 14 拍。
- 模式切换采用“三道清音”：128 拍全关扫描 + `reset_all` 单拍清零 + 488 样本（5 ms）静音窗；防爆音位于 RTL 与 Dock 板载 `PA_EN`，不在自制 PCB 上实现。

## 5. 硬件方案

- **FPGA 平台**：Sipeed Tang Mega 138K Dock（`GW5AST-138C`）；音频沿用 Dock 板载 PT8211 与 3.5 mm/2×3W 输出，不在自制板上重复设计 DAC/重构滤波。
- **PCB1 输入调理与隔离板**（100×70×1.6 mm，2 层 FR-4）：
  - 13 键：220 Ω 串联 + 100 nF 对地 + FPGA 内部上拉；TS-1117 四脚轻触开关 + 硅胶键帽。
  - 6 路光电：12V 侧 1.2 kΩ 限流，副边 10 kΩ 上拉、220 Ω/100 nF，PC817 5 kVrms 隔离。
  - 双路 ToF：两条独立 I2C（A: A18/D15；B: F14/F13），4.7 kΩ 上拉 + 330 Ω 串联 + 100 µF/100 nF 本地储能。
  - 4 路 EC11：100 Ω / 10 kΩ / 100 nF，**预留**，本版不使用。
  - 电源与地：H3 3.3V 输入 + F1 0.5A PTC；GND12/GND 1.5 mm 隔离，R15 0 Ω 单点桥接。
- **机械结构**：两件式 PETG FDM 外壳；13 键双 Ø2.2 mm 导柱键床（白键 10.50 mm、中心距 11.50 mm）；双路 ToF 两段式导光筒（分件面 Z=22.124 mm、模块顶面以上净深 18.5 mm）。
- **7 寸屏**：ATK-MD0700 800×480，SSD1963 16-bit 8080 + GT911/FT5206 自适应触控；经 **34P FPC→J14 40P 排线**接入，不使用 P34-P40 转接板与 piano6 PCB。

## 7. 快速开始

### 7.1 环境

- 高云 **Gowin EDA V1.9.12.04**（含 `gw_sh.exe` 与 `programmer_cli.exe`）
- Python 3.8+（上位机仅需 `pyserial`）
- Tang Mega 138K Dock + 自研 PCB1 + 7 寸屏 + 13 键/6 光电/双 ToF 外设

### 7.2 编译与烧录

```powershell
cd fpga_spark/lcd_test
python build_j14.py
python burn_lcd_j14.py
```

### 7.3 上位机

```powershell
cd fpga_hank
pip install -r host/requirements.txt
python host/piano_gui.py --autoconnect
```

串口：`115200 bps，8N1`；上位机只下发音符/CC 报文，不参与音频合成。

### 7.4 运行模式

| 模式 | 用途 | 说明 |
|---|---|---|
| `MODE=3` | **整机交付** | TDM32 192 路 + 8 模块效果器 + 7 寸 UI + 13 键/6 光电/双 ToF |
| `MODE=1` | PC 控制/回归 | 48 路全并行对比基线 + UART/MIDI |
| `MODE=2` | 32 谱峰取证 | `tone_bank` + `adsr`，200 Hz～6,400 Hz 等间隔 32 峰 |
| `MODE=0` | 脱机放歌 | 4 首公有领域曲目自动播放 |

## 8. 验证与证据

- **32 谱峰**：`MODE=2` 数字样本 32/32 命中、0 杂散；真板录音 32/32 命中，并完成 PT8211 ZOH 镜像与 48 kHz 声卡混叠机理拆解。
- **确定性延迟**：48 路对比基线 512 相位全枚举，Min 516 clk / P50 772 clk / P99 1,021 clk / Max 1,027 clk；整机 2 ms 示波器实测。
- **时序收敛**：10 份归档 `.tr/.rpt`；MODE=1 核心终版 0 Setup / 0 Hold，WNS +0.040 ns；pipeline 构建 +0.186 ns。
- **形式化/回归**：200 万例一热分配器等价性；10,242 点输出级流水线逐值比对；31 套测试台。
- **证据位置**：`fpga_hank/_research/piano/evidence/`、`fpga_hank/docs/evidence/`、`fpga_hank/docs/BITSTREAM-FINGERPRINTS.md`。
