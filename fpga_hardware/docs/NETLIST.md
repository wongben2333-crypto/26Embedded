## 5. 光电电平转换

以下为已上板验证的面包板 S9012 方案，仅作为历史参考。自研 PCB v1 使用 PC817，
连接见 `PCB-SCHEMATIC-SPEC.md`。

```
             +3V3
               │
             [10k]
               │
 黑线 ─[47k]──┼── E（发射极）──┬── FPGA 输入（J13-16..21）
               │                │
             [47k]           C（集电极）── GND
               │
              GND            （基极 B 接两只 47k 的中点）
```

实测：未遮挡 **3.3 V**（读 1）、挡光 **0.6 V**（读 0，低于 VIL 0.8 V）。
元件（每路）：S9012 ×1、47 kΩ ×2、10 kΩ ×1。

### 7.1 J5（FPC-40P，LCD 接口）能否当 IO？（2026-10-24 查证）

**部分可以，但不建议用。**

| 事实 | 依据 |
|---|---|
| 官方 60K / 138K 引脚文件里，LCD 段**只定义了 5 个球**：`LCD_CTP[0..3]` = **W16 U16 T16 T15**、`LCD_BL` = **P20**，全部 `LVCMOS33 / BANK_VCCIO=3.3` | 两版 `tang_mega_*_pins.cst` 的 `====== LCD ======` 段 |
| 其余 35 针（RGB 数据 / HS / VS / DE / PCLK）**在引脚文件里没有任何网络名与球号** | 全表前缀统计：`LCD_CTP`×4、`LCD_BL`×1，无 `lcd_r/g/b`、无 `dpi_*` |
| 这 5 个球（W16 U16 T16 T15 P20）**当前 cst 未使用** | `constr/fpga_hank_60k.cst` 中无这些球 |

**结论**
1. 只有 **5 个球（触摸 ×4 + 背光）** 电气上可当 3.3 V GPIO；
2. 另外 35 针**无法从官方文件确定球号** ⇒ 不能可靠约束；真要用必须去 31004 原理图
   J5 页逐针推导，并确认 60K SOM 确实把那些球引到 BTB —— 风险高、收益低；
3. **物理上是 0.5 mm FPC-40P**，必须做转接排线，不能像 J13 那样插杜邦线；
4. J5 是板载 RGB LCD 的专用口（含背光/触摸），以后上屏就会被占。

**扩展 IO 的优先顺序**：J13 剩余 7 球（2.54 mm，最好接）→ J8 剩余 5 球
（`AA19 AB20 AA20 AA21 AB21`）+ J9 的 `T21`/`R19` 与 4 个 LED 球（`T18 R18 R17 P16`，
本板无 LED）= 最多 11 个 2.54 mm 排针脚，但 **J8/J9 与音频同 BANK7，只适合慢速/静态信号**
（键、编码器、光电都可以；不要再做 I²C 或高速）→ J5 的 5 个球只作最后备用。

```
                        └── EC11 → 音量 dB LUT ───────────────────────────┘（混音后增益）
```
