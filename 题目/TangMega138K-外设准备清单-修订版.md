## 一、板载资源盘点（Dock 版家底）

### 1.1 算力与存储 —— 完全够用
- **FPGA**：GW5AST-LV138PG484A —— **138,240 LUT / 138,240 FF**
- 片上存储：S-SRAM 1080 Kb + B-SRAM **6120 Kb（340 块）**
- 乘法器：**298 个 18×18** ｜ PLL ×12 ｜ 全局时钟 16
- **硬核 RISC-V：AE350 @800MHz**（跑参数配置/UI，不跑合成算法）
- 内存：**1GiB DDR3**（512MiB × 2）｜ Flash 128/64Mbits × 1
- **SD 卡槽 ×1**（1-bit SDIO/MMC 或 SPI）

> **对电子乐器的意义**：32 复音预估仅需 **~6K LUT + 32 DSP**，资源余量极大；DDR3 可做长延迟线 / 多效果器。

### 1.2 音频输出 —— ✅ 板载自带
- **板载音频 DAC：PT8211**（16-bit R-2R，**LSB-justified 格式，无 MCLK**）
- **3.5mm 耳机口 ×1**（立体声输出，无 Mic）
- **Speaker 接口 ×2（2 × 3W）** —— Dock 为双路，**可直接接 2 个喇叭做立体声** `[修订]`
- 参考引脚（以官方 pin constraint 为准）：
  - HP_BCK **Y17** ｜ HP_WS **AB17** ｜ HP_DIN **AA16** ｜ PA_EN **AB16（低电平使能功放）**
- **MS5351 时钟发生器 ×1**（原为 SerDes 提供 RefClk，经底板串口控制）—— 若将来外接需要 MCLK 的 I2S DAC 或走 96kHz 路线，可产生精确音频时钟 `[新增]`

> ⚠️ **不要试图用 HDMI 传音频** —— 真 HDMI 音频需 data island + TERC4 编码，纯 DVI 发射器做不到。

### 1.3 显示与可视化 —— 基本够用
- **DVI TX ×1**（HDMI 输出，**与 DVI RX 互相占用**，只能二选一）
- **RGB 接口 ×1**（支持 RGB888 屏幕）
- 板载 **8 个 PMOD LED** + 4 个电量指示灯
- **WS2812 ×1**（与 aRGB 灯带连接器同数据引脚，可外接灯带）

> **对电子乐器的意义**：频谱 / 李萨如 / 波形可走 HDMI；**LED 演奏指引可直接用板载 8 灯 + WS2812 灯带**。

### 1.4 交互输入 —— ⚠️ 严重不足，需扩展
- 板载按键仅 **3 个用户按键 + 1 个 reconfig 键** —— **做不了琴键**
- **PMOD ×2**（**与某个 40P 排针、DVP 接口复用**）`[修订]`
- **40P 排针 ×2**（琴键接线主要走这里）—— **两个排针不等价**，详见修订 3 `[修订]`
- **ADC ×2**（底板 2 路**差分**输入通道）—— 板载 ADC 是 **10-bit / 输入 0~1V**，用于力度需注意量程，详见修订 2 `[修订]`

> **结论**：**演奏琴键必须自己扩展**（电容触摸电极 / 光电对管 / FSR / 轻触按键）。

## 二、一句话结论

**音频通路（DAC + 功放 + 喇叭接口）板子全自带**，只需买 **2 个 3W 喇叭**（Dock 双路，可做立体声）或一副**耳机/有源音箱**，插上就能响——不用画 DAC 电路、不用买 I2S 功放模块、不用做 RC 低通。

真正需要花心思的只有两件事：
1. **演奏琴键**（要自己设计制作）
2. **调试验证工具**（尤其是能看频谱的设备，用来证明"32 个独立谱峰"）

**参考预算**：基础配置约 **200–300 元**（不含示波器/显示器），全配约 **450–650 元**。

## 三、本版修订要点（相对上一版，共 6 处）

### 🔴 修订 1（更正 · 好消息）：IDE 不用买商业版
- 装 **教育版 IDE ≥ V1.9.11.03** 即可（商业版 ≥ V1.9.9），**教育版不需要 License**，直接下载就能用。
- 上一版把"需商用版 + Lic"当成 138K 的通病，**那是 138K Pro 的情况，Dock 不适用**。
- ⚠️ **但 Device Version 必须选对**：2025 年 7 月后芯片由 **B 步进改为 C 步进**（B 步进已停产）。**C 步进必须在 IDE 里选 Device Version: C**，否则 **SSRAM 不可用 + 出现奇怪的兼容性问题**。
- **分辨方法**：看 **FPGA 镭雕印记第三行第五位** —— 字母 `C` = C 步进，`B` = B 步进（适用所有高云 FPGA）。
- **固化到 Flash**：推荐 `exFlash Erase,Program thru GAO-Bridge 5A`（需 ≥V1.9.11.03）或 `Arora V`（需 ≥V1.9.12）；建议用独立的 **1.9.12 SP1 Programmer**。
- 报错"找不到型号 GW5AST-LV60PG484A" = **IDE 版本过老**，升级即可。

### 🔵 修订 2（影响方案）：力度采样别硬啃板载 ADC
查高云 GW5AST 数据手册（DS1239）：内置 **8 通道 10-bit Delta-Sigma ADC**，138K 器件有 **2 个** ADC。

| 参数 | 数值 |
|---|---|
| 分辨率 | **10 bit** |
| 采样时钟 | **< 2 MHz** |
| **输入范围** | **0 ~ 1 V**（⚠️ 不是 3.3V！） |
| 信号带宽 | **1 kHz** |
| 参考电压 | 内置 |
| 底板接口 | **2 路差分输入** |

**三个坑**：
1. **输入只有 0~1V** —— FSR 分压必须压到 1V 以内
2. **差分输入** —— 负端要接参考/地
3. **10-bit** 对力度够用，但量程设计不当易削顶

**修订建议**：优先直接买 **ADS1115 模块**（I2C，16-bit，0~3.3V 单端，约 15 元），避开 1V 量程 + 差分两个坑；想省板子/想加分再考虑板载 ADC。第三条路（不依赖 ADC）：**RC 充放电时间测量**（同电容触摸原理）。

### 🔵 修订 3（影响方案）：两个 40P 排针不等价
- Dock 有 **2 个 40P 排针**，但其中**一个与 PMOD0 / PMOD1 及 DVP(CAM0) 复用**。
- litex-boards 官方平台定义注释：**PMOD0 与 SDRAM1_Dx 共享**、**PMOD1 与 SDRAM1_Ax 和 CAM0 共享** —— 也就是说 PMOD0/PMOD1 的引脚就是某个 40P 排针的一部分。
- **做法**：**琴键请接到"独立的那一个" 40P 排针上**；如果非要用 PMOD 插模块，就要牺牲对应 40P 引脚。
- 40P 排针的**第 11 / 12 脚是 5V / GND**（可给外部模块供电，接线时注意别接错）。
- **接线前必须先对照官方 pin constraint / 原理图确认哪个是哪个。**

### 🟢 修订 4（清单新增）：喇叭买 2 个
Dock 的 **Speaker 接口 ×2（2 × 3W）**，可直接接 **2 个喇叭做立体声**。对"合唱 / 立体声延迟 / 立体声像"这类效果的演示明显更好。预算 +10 元。

### ⚫ 修订 5（清单删减）：PMOD 模块可以不买
Dock 只有 **2 个 PMOD**（Pro 有 3 个），且与 40P 排针复用。上一版清单里的 **Sipeed PMOD_BTN4+4 / LEDx8 建议删除** —— 直接把琴键和 LED 接到 40P 排针更划算（省 PMOD 占用，也省约 30 元）。

### 🟣 修订 6（可忽略）：收发器 / PCIe / MIPI / EEPROM 等差异与本题无关
Dock：4 路收发器 @8Gbps、PCIe x1/x2/x4、**无 MIPI CSI**、无 EEPROM、无 M.2、无 SFP+、Flash 128/64Mbits ×1。
这些对电子乐器项目**完全无影响**。核心资源与 Pro **完全一致**：138,240 LUT / 6120Kb BSRAM / 298 乘法器 / 12 PLL / AE350@800MHz / 1GiB DDR3 —— **32 复音的资源预算不受任何影响**。

## 七、避坑提醒（11 条，含 3 条本版新增）

1. **供电不足会导致启动失败**。三种可靠方案任选：① 12V DC（DC5521）② USB3.0 + USB-DEBUG 双 5V USB ③ 3.7V 锂电池（≥3.6V，持续放电 ≥600mA）。调试阶段强烈建议用 12V DC。

2. **不是拨开关开机** —— 要**长按 PWR 键 2 秒**切换开关机状态（PWR 键在 HDMI 接口旁边）。很多人第一次以为板子坏了。

3. **IDE 用教育版即可（≥V1.9.11.03，免 License），但 Device Version 必须选对** `[修订]` —— 芯片 **GW5AST-LV138PG484A**，封装 **PBG484A**。2025 年 7 月后为 **C 步进**，**必须选 Device Version: C**，否则 **SSRAM 不可用 + 奇怪兼容性问题**。分辨：看 FPGA 镭雕印记**第三行第五位**字母。报错"找不到型号"= IDE 版本过老。

4. **IO 电压必须 3.3V**。用 GPIO 排针与外部通信时，过高电压会**永久损坏** PCBA。接自制琴键/传感器前先确认电平。

5. **DVI TX 与 DVI RX 互相占用** —— 同一路物理接口只能当输出或输入，二选一。做可视化时用 TX（输出）。

6. **两个 40P 排针不等价** `[修订]` —— 其中**一个与 PMOD0/PMOD1 及 DVP(CAM0) 复用**（litex 平台定义：PMOD0 与 SDRAM1_Dx 共享、PMOD1 与 SDRAM1_Ax 和 CAM0 共享）。**琴键请接独立的那一个 40P 排针**；用了 PMOD 就要牺牲对应 40P 引脚。**接线前必须对照官方 pin constraint / 原理图**。40P 排针**第 11/12 脚是 5V/GND**。

7. **板载 ADC 是 10-bit / 输入 0~1V / 差分** `[新增]` —— GW5AST-138 内置 8 通道 10-bit Delta-Sigma ADC（138K 有 2 个），**输入范围仅 0~1V**、**差分输入**、采样时钟 <2MHz、信号带宽 1kHz。**用 FSR 做力度时必须把分压压到 1V 以内并把负端接参考/地**；嫌麻烦就直接上 **ADS1115**。

8. **板载音频 DAC 是 PT8211，走 LSB-justified 格式（不是标准 I2S），且没有 MCLK**。写代码时别照搬标准 I2S 时序，否则会有杂音或无声。参考引脚 HP_BCK/HP_WS/HP_DIN（以官方约束文件为准）。

9. **不出声先查 PA_EN** —— 功放使能是**低电平有效**，必须驱动为 0 才响（参考引脚 AB16，以官方为准）。

10. **不要用 HDMI 传音频** —— 真 HDMI 音频需要 data island + TERC4，纯 DVI 发射器做不到。音频一律走 **3.5mm 耳机口 / Speaker 接口**。

11. **固化到 Flash 要用对模式** `[新增]` —— 推荐 `exFlash Erase,Program thru GAO-Bridge 5A`（需 ≥V1.9.11.03）或 `Arora V`（需 ≥V1.9.12）；建议使用独立的 **1.9.12 SP1 Programmer**，兼容性更好。
