怎么读这张图：J13 每个格子右侧的小字（E14 / C15 / B17…）就是板上丝印的 FPGA 球位，直接照丝印找脚接线即可，不必去数第几根。
如果板上印的是 D0 / D1 / A0 这类 SDRAM 网络名（不同批次丝印可能不同），请对照下方第二节表格「底板网络」列换算成球位，再定位到排针脚位。
屏幕侧（P1）标注的是模块自身丝印：M1（pin29）= 空脚；M0（pin30）= 触摸 I2C SDA。手册把它印成 MI/MO，实为数字 M1/M0。

J13 富余：pin 29–40（EXIO0/1、CAS、RAS、CS、BA0/1、A10、A0–A3 等 12 个脚）全部空闲，可留给按键 / 旋转编码器 / WS2812。

三、⚠ 连错会烧板的 4 根线

只有电源和地接错才会烧；信号之间接错最多不工作

  1. J13 pin11（5V）紧贴 pin12（GND） —— 整体偏一格就是 5V 直接对地，板载 5V 是 5A DC-DC + 1A 功率开关，会烧线/烧排针。
  2. 屏幕 pin28（5V）紧贴 pin27、pin26（GND） —— 同样错一格即短路。
  3. J13 pin35 / pin39 不是电源 —— 分别是 SDRAM0_BA1(C20) 和 SDRAM0_A2(C19)，是 FPGA 输出脚，接 3.3V 或 GND 会过流烧脚。J13 上没有任何 3.3V。
  4. 屏幕 pin28 只能来自 J13 pin11 —— 误接成某个 FPGA IO 时，模块要抽 0.3~0.6A，IO 只能给十几 mA，会烧 IO。

上电前 3 道检查

  • 断电，电阻档：J13 pin11 ↔ pin12 不短路；P1 pin28 ↔ pin26 不短路
  • 断电，通断档：P1 28 ↔ J13 11；P1 22/26/27 ↔ J13 12；除这 4 根外，屏幕任何脚都不应通到 J13 的 11 或 12
  • 上电（先不插屏）：量 J13 pin11 对地 = 5V ±5%，确认后再插屏
背光提醒：背光不走引脚，由 SSD1963 的 PWM 寄存器经 LCD_BL 驱动 MP3302 的 EN，且该脚有 4.7k 下拉默认关闭。初始化必须写 0xBE, 0x05, <亮度>, 0x01, 0xFF, 0x00, 0x00，否则屏全黑。
调试建议：第一次上电先发 0xA1 读 ID，返回 0x0000 即说明 16 根数据 + CS/RS/RD 全通。
物理连接：J13 是 2.54mm 排针，屏幕 P1 也是 2.54mm 排针 —— 用 2.54mm 双排杜邦线（母对母）或做一块 40P→34P 转接小板即可，不需要 0.5mm FPC 转接板。
注意：底板另有 J5（0.5mm 40P FPC）是 RGB 屏口，与 J13 完全无关，不要接错。
