# 升级指引：立创EDA 专业版 升到带命令行/MCP 的版本

> 给用户看的。**你只需要做"下载 → 备份 → 安装 → 验证"四步**，其余我们来做。
>
> 为什么要升级：**我们要在立创EDA 本体里画板**（而不是用脚本硬搓工程文件）。
> 立创EDA 从某个版本起自带**命令行客户端 + 本地桥接服务**，能让我们**驱动真编辑器**画板、
> 跑 DRC、导 Gerber —— 画出来的板子**你能继续在软件里编辑**。
> ⚠️ 而这个功能**要求 v4.1.60 及以上**，**你现在这个版本没有**（我实测确认，见下）。

## 四、第三步：验证装好了（**打开一个终端跑这一条**）

按 `Win+R` → 输入 `powershell` → 回车，然后粘贴：

```powershell
easyeda-pro doctor
```

**期望**：返回一段 JSON，里面有 `"ok": true` 之类的字段（说明它找到了编辑器端点）。

**如果报"无法识别 easyeda-pro"** ⇒ 用完整路径试：
```powershell
& "C:\Program Files\EasyEDA-Pro\easyeda-pro.exe" doctor
```

**再确认一下版本**：
```powershell
(Get-Content "C:\Program Files\EasyEDA-Pro\resources\app\package.json" -Raw | ConvertFrom-Json).version
```

**把这三条命令的输出发我们**就行（截图或复制文字都可以）。

1. 用 **`easyeda-pro open --path ...`** 打开/新建工程
2. 用 **`invoke`** 在编辑器里执行 JS，调用**扩展 API** 画板：

3. 用官方能力**导 Gerber / BOM / 网表 / 截图**、**跑 DRC**

**⚠️ 我们不会**：替你下单、替你付款、替你买器件（这是你明确保留的权限）。

## 附：为什么不能"用脚本生成工程文件"了（你之前那句话是对的）

我们试过用 Python 直接生成 `.epcb` 工程文件，**撞了两代格式墙**：
- 你电脑上旧工程用的是**数组式旧格式**（`["DOCTYPE","PCB","1.7"]`）
- 官方现行的是 **key-value 新格式**（`{"type":"DOCHEAD",...}||{...}|`）

**就算猜对了格式，生成的板子你也没法在 EDA 里继续编辑**（改一个焊盘都要回头改脚本）。
**⇒ 你说"直接在嘉立创EDA上画"是对的路线。** 我们已经把**几何、丝印表、BOM、引脚表**
全部整理好了，**换成驱动真工具之后这些全都能直接复用，不会白费。**
