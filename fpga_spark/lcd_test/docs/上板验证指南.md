## 0. 三十秒速览

| 级 | 内容 | 你要看到/听到什么 |
|---|---|---|
| **S0** | 时钟/烧录冒烟 | 4 个 LED 在按二进制跳动 |
| **S1** | 两个按键 + 去抖 | 按住 AB13 → 灯亮；每按一下计数 +1；按 Y12 → 清零 |
| **S2** | **固定 440 Hz 正弦** | **耳机里听到持续稳定的「啦——」（A4 音）** |
| **S3** | 按键触发单音 + ADSR | 按键时音「起来 → 保持 → 消失」 |
| **S4** | 按键切 4 种音色 | 音色明显变；LED 显示音色号 |
| **S5** | 32 路复音测试模式 | 录音 + FFT 数出 **32 根柱子** |
| **S6** | 延迟测量 | 测出「按键→出声」的毫秒数；LED 直接给合格判定 |

**第一次上板，请严格按 S0 → S1 → S2 的顺序做。** S2 是最关键的一级：它第一次证明「真的出声」。

## 5. 逐级验收

每一级都说清三件事：**你会看到什么** / **怎么算通过** / **没反应先查什么**。

### S0 —— 时钟与烧录冒烟

| | |
|---|---|
| **现象** | 4 个 LED 一起按二进制跳动：`led[3]` 最慢（约 1.5 Hz 翻转，肉眼明显），`led[0]` 最快（约 12 Hz，看起来像半亮） |
| **通过判据** | LED 在**变化**。只要在变，就说明：配置成功、50 MHz 时钟在跑、复位正常 |
| **顺带** | 三个「打标脚」输出 3 种不同频率的方波，用来**定位引脚**（见 §9） |
| **没反应先查** | ① 供电是否单口掉电（§2）② `.fs` 是不是烧进去了 ③ 是不是烧错了器件版本 |

> S0 里耳机**不会有声音**（功放被故意关掉，避免底噪让你误判 S2 没声音）。这是正常的。

### S1 —— 两个按键 + 去抖

| LED | 含义 |
|---|---|
| `led[0]` | 心跳（一直闪，约 1.5 Hz） |
| `led[1]` | **AB13 按住时亮** |
| `led[3:2]` | **AB13 的按下次数**（二进制 00→01→10→11→00…） |

- **通过判据**：
  1. **按住 AB13**（丝印上的用户键）→ `led[1]` 亮，松开灭；
  2. **按一下 AB13** → `led[3:2]` 加 1；
  3. **按一下 Y12**（第二个用户键）→ `led[3:2]` **清零**。
- **这一步证明了什么**：输入通路 + 2.621 ms 去抖 + 两个独立按键都在工作。
  （去抖的效果：**轻触开关的机械抖动不会让计数乱跳**，按一下就是 +1。）
- **没反应先查**：
  - 两个键**都不是** AB13/Y12 的话 → 按了没反应，见 §9 的按键说明；
  - 如果计数一次跳好几下 → 去抖参数需要加大（`build_smoke` 用的 `DB_MAX = 131071`，
    见 `rtl/smoke/smoke_top.v`，改这里要重新构建）。

### S2 —— ★ 固定 440 Hz 正弦，第一次出声

| LED | 含义 |
|---|---|
| `led[0]` | 心跳 |
| `led[1]` | 音频数据在流动 |

- **现象**：插上耳机，**听到一个持续、稳定的「啦——」**。
- **音高核对**：这是 **A4 = 440 Hz**（钢琴中央 C 上面那个 A，调音器 App 应显示 A4）。
  频率字 `19351405`，实际 440.0000080 Hz，误差 0.000002%。
- **通过判据（耳机法）**：耳机里能听到持续音，且用调音器/频谱 App 看是 **440 Hz**。
- **通过判据（没耳机时，声卡/麦克风法）**：
  1. 用电脑（或手机）**麦克风**对着板载扬声器座 / 耳机口录 10 秒；
  2. 用任意频谱 App / Audacity 的 `Analyze → Plot Spectrum` 看；
  3. **在 440 Hz 处有一根明显的柱子** = 通过。
- **⚠️ 注意**：上电后音量会**先淡入**（起音 83.9 ms）**到满幅，再花 21 ms 回落到保持电平**，
  约 0.12 秒后稳定不变。这是包络在起作用（S2 把 gate 恒置 1，包络爬到满幅再衰减到保持段），**不是故障**。
- **RTL 仿真已实测（不是上板，但可作参考）**：
  - 送进 DAC 的 9766 个采样点里 **4846 个正 / 4847 个负** → 正负对称，**负半没有被吃掉**；
  - 实测频率 **440.0252 Hz**；BCK 周期 **320.0 ns**（⇒ fs = 97656.25 Hz，与频率字配套）；
  - 仿真 0 error / 0 warning。
- **没反应先查（按这个顺序）**：
  1. **耳机插的是板载 3.5 mm 口**，不是板子其它孔；插到底；
  2. **音量**：用板载扬声器座时要接喇叭；耳机口音量是固定数字电平，靠耳机灵敏度；
  3. **烧的是不是 S2**（`smoke_top_s2.fs`）；
  4. 看 `led[1]` 亮不亮 —— **亮 = 音频数据在流**，不亮 = 音频通路没跑起来；
  5. 供电是不是单口掉电重启（§2）。

### S3 —— 按键触发单音 + 听得出 ADSR

- **现象**：不按键时**静音**；按住 AB13，音会**「起来」（约 84 ms 淡入）→ 保持**；
  松手后**约 63 ms 内「消失」（淡出）**。
- **LED**：`led[0]` 心跳、`led[1]` 按住、`led[2]` 包络非零（按住后会亮，松手后过一会儿灭）。
- **通过判据**：**耳朵能明确分辨「起音」和「释放」两段过渡**，而不是「啪」地一下开关。
- **没反应先查**：如果听起来是硬开硬关（没有淡入淡出），说明你烧的不是 S3
  —— 生产版 `top.v` 的包络参数起音只有 40.96 µs，**耳朵是听不出包络的**
  （这是本项目已确认的一处注释/参数错误，见 `_smoke-test/REPORT.md`）。

### S4 —— 按键切 4 种音色

| 音色号（`led[3:2]`） | 波形 |
|---|---|
| `00` | 纯正弦（柔和，像 S2/S3） |
| `01` | 带限锯齿（明亮） |
| `10` | 带限方波（中空） |
| `11` | 带限三角波（更柔和但有厚度） |

- **操作**：**按一下 AB13 换下一个音色**，**按一下 Y12 换上一个音色**（0↔3 循环）。
- **通过判据**：音色**明显**变化，而且 `led[3:2]` 显示的号数与听到的音色对得上。
- **这一步证明了什么**：音色是**用户可控**的，不是定时器自动轮换
  （生产版 `top.v` 用的是计数器自动轮换，不可控）。

### S5 —— ★ 32 路复音测试模式（赛题必备取证）

| LED | 含义 |
|---|---|
| `led[3:1]` | 常亮（表示 32 路全部在发声） |
| `led[0]` | 心跳 |

- **现象**：耳机里是**一个很厚的和弦式嗡鸣**（32 个音同时响，200 Hz 间隔，从 200 Hz 到 6400 Hz）。
- **通过判据**：**录音 + FFT 能数出 32 根独立谱峰**。完整步骤见 §7。
- **快速定性检查（零设备）**：用手机上的频谱 App 对着耳机/喇叭，
  应该看到**间隔均匀的梳状谱峰**（每 200 Hz 一根）。能看出梳状就说明是多音同时发声。

### S6 —— 延迟测量

| LED | 含义 |
|---|---|
| `led[0]` | 心跳 |
| `led[1]` | 按住 AB13 |
| `led[2]` | **本次测量「按键→出声」< 10 ms**（赛题基础要求②的硬指标） |
| `led[3]` | **本次测量「按键→出声」< 5 ms**（拓展要求③） |

- **零仪器自测法（推荐先做这个）**：
  1. 按一下 AB13 再松开；
  2. 看 `led[3]` / `led[2]`：**`led[3]` 亮 = < 5 ms（优秀）；只有 `led[2]` 亮 = < 10 ms（达标）；
     两个都不亮 = 超过 10 ms（不达标，要查）**。
  3. 注意：**必须先按过一次键**再判读（没按过之前两个灯都不亮）。
- **⚠️ 这是 FPGA 自测**，不是独立测量。它数的是芯片内部从按键引脚第一次被拉低，
  到音频样本幅度越过阈值之间的 50 MHz 时钟数，**包含去抖窗口**。
  独立测量（示波器 / 声卡）应当复现同一量级；**两者不一致时，先怀疑测量方法，而不是直接信这个灯**。
- **定量测量（示波器 / 声卡）见 §8。**
- **理论延迟预算**（按 RTL 参数算出来的，不是实测）：

  | 环节 | 时间 | 说明 |
  |---|---|---|
  | 按键输入两级同步 | 0.04 µs | 2 个 50 MHz 时钟 |
  | 按键去抖 | **2.621 ms** | 2^17 = 131072 个 50 MHz 时钟，**主要贡献项** |
  | 包络爬到可闻阈值 | 0.035 ms | 实测 34.8 µs（3 个采样点 @ 97.656 kHz） |
  | **合计（到 DAC 收到非零样本）** | **2.656 ms** | 确定性，无软件调度抖动 |
  | DAC 转换 + 功放 + 耳机 | < 1 ms | 器件级，未实测 |

  ⇒ **< 5 ms**，满足赛题「基础要求② ≤10 ms」，也够拓展③的「≤5 ms」。
  **必须由你的实测确认**（可用 §8.1 示波器法或 §8.2 声卡法）。

- **RTL 仿真已实测（ModelSim，不是上板）**：`sim/tb/tb_smoke.v` 的 `tb_smoke_s6` 测出
  **物理接触 → 出声 = 2.656 ms**（去抖窗口 2.621 ms + 音频通路 34.8 µs），
  并且 **FPGA 内部自测计数器 `lat_val` = 132812 clk = 2.6560 ms，与外部边沿测量差 < 0.001 ms**
  —— 说明 LED 上那套「<5 ms / <10 ms」判定灯的口径是可信的。
  **但这是仿真值**：上板后请把示波器/声卡测到的数字填进报告。

## 7. S5 频谱取证：数出 32 根谱峰

### 7.1 先确认工具本身没坏（不需要硬件，30 秒）

### 7.2 录音

**方案 A：电脑声卡 + 3.5 mm 线（最准）**
1. 一根 3.5 mm 公对公线，从板子的耳机口接到电脑的 **Line-in**（线路输入）；
2. 用 **Audacity**（免费）录音：采样率选 **48000 Hz**（或 96000 Hz），录 **5~10 秒**；
3. 导出成 **无文件头的裸 PCM**：
   `文件 → 导出 → 导出为其它非压缩格式 → 格式：其它非压缩文件 / 头部：RAW (header-less) / 编码：Signed 16-bit PCM`
   例如存成 `C:\Users\Danny\Desktop\FPGA competition\_smoke-test\s5_rec.raw`
   （⚠️ check_peaks.py **不认 WAV 文件头**，必须导出成 header-less RAW。）

**方案 B：麦克风录（没有线也能做）**
1. 电脑或手机麦克风对着板载扬声器座/耳机口，录 5~10 秒；
2. 同样导出成 RAW signed 16-bit PCM。
   （麦克风录会引入环境噪声，可能让杂散变多，但 32 根主峰仍然应该清楚。）

**方案 C：手机频谱 App（零成本定性）**
对着耳机/喇叭看频谱，应该看到间隔 200 Hz 的梳状谱峰。

## 8. S6 延迟测量：三种方法

**要测的定义**：从**按键被物理按下（电接触第一次闭合）** 到**音频通路输出第一个可闻样本**的时间差。

### 8.1 方法 A —— 示波器（最准，推荐）

**接线**（3 个打标脚都在板子同一组排针上，见 §9）：

| 示波器 | 接板子 | 信号含义 |
|---|---|---|
| CH1 | `DBG_KEY` (Y22) | 按键**原始**电平，未去抖。按下瞬间就变高 |
| CH2 | `DBG_AUDIO` (AB22) | 音频通路**已经送出可闻样本**，变高 |
| （可选 CH3）| `DBG_GATE` (AB21) | 去抖**之后**决定了「应该发声」 |

**怎么读**：
1. 触发设成 **CH1 上升沿**、单次（Single）模式；
2. 按一下 AB13；
3. 读 **CH1 上升沿 → CH2 上升沿** 的时间差 = **「按下→出声」延迟**；
4. 读 **CH1 → CH3** 的时间差 ≈ **去抖窗口**（应该约 2.62 ms）；
5. 多按几次（≥20 次），记下最小/最大/平均，一起写进报告。

**预期**：CH1→CH2 约 **2.6~2.7 ms**。
**注意**：如果按键抖动时间长，CH3 的边沿会后移，这是真实存在的机械抖动，不是设计问题。

### 8.2 方法 B —— 声卡双声道（没有示波器）

思路：把**音频**送进声卡的**左声道**，把**打标信号**送进**右声道**；
两个信号走**同一个 ADC**，所以声卡自己的延迟会**互相抵消**，剩下的是我们要测的时间差。

**需要**：
- 3.5 mm 立体声（TRS）插头一个 + 两根细线（或一根公对公线剪开用）；
- 电阻：**10 kΩ 和 1 kΩ 各一只**。

**接线**：

```
TRS 插头（插电脑 Line-in）
  Tip    (左) ─── 从板子耳机口的输出 ──────────────── 音频
  Ring   (右) ──[10kΩ]── DBG_AUDIO (AB22) ──[1kΩ]── GND(板子)
  Sleeve (地) ─── 板子 GND
```

- 分压后 DBG_AUDIO 的 3.3 V 变成约 **0.3 V**，对 Line-in 是安全电平。
- ⚠️ **优先插 Line-in（线路输入）**。如果只有 **Mic-in**（麦克风口），
  有些机器会给麦克风供偏置电压，**务必确认接口类型后再接**，不确定就不要接。
- ⚠️ **不要**把 3.3 V 直接接进声卡输入。

**怎么读**：
1. Audacity 录**立体声**，采样率 48000 Hz；
2. 按一下 AB13；
3. 放大波形，找**右声道的台阶上升沿**（= 按键按下）和**左声道波形开始振荡的位置**（= 出声）；
4. 两个位置的时间差 = 延迟。Audacity 里把时间轴单位切到毫秒就能直接读。

**精度局限**：
- 采样点间隔 = 1/48000 s = **20.8 µs**，所以量化误差 ≤ ±21 µs；
- 声卡是**交流耦合**的，所以右声道那个「台阶」会变成「跳上去再慢慢回落」——
  **边沿位置仍然准确**，读边沿即可；
- 主要误差来自「怎么判断音频开始」：建议把判据定为**左声道幅度超过满幅 1%** 的第一个点。
- 综合误差量级：**±0.1 ms 以内**，对 10 ms 的指标足够了。

### 8.3 方法 C —— 零仪器（FPGA 自测 + 耳朵）

1. **S6 的 LED 自测**（§5 S6）：`led[3]`/`led[2]` 给「<5 ms / <10 ms」的合格判定。
   这是**真实的计数器**（不是估算）：ModelSim 仿真实测内部计数器与外部边沿测量
   **吻合到 0.001 ms 以内**（`_smoke-test/REPORT.md` §5.2）。
   **但它测的是芯片内部，属于"自测"** —— 写报告时建议至少再用方法 A 或 B 独立复核一次。
2. **耳朵判定**：按住再松开，如果听不出任何「延迟感」——这**只能排除上百毫秒级的延迟**，
   **不能证明 ≤10 ms**。写报告时**不要**把这一条当成 10 ms 的证据。

## 9. 打标脚与按键怎么找（不用看原理图）

S0 里三个打标脚会各自输出**不同频率**的方波，用它来认脚：

| 引脚 | S0 输出的频率 | 用途 |
|---|---|---|
| **Y22** | 1.49 Hz | `DBG_KEY` |
| **AB21** | 2.98 Hz | `DBG_GATE` |
| **AB22** | 5.96 Hz | `DBG_AUDIO` |

**认脚方法**（任选）：
- **万用表**：打到频率档（Hz），黑表笔接板子 GND，红表笔挨个碰排针，
  读到 1.5 / 3.0 / 6.0 Hz 的三个脚就是它们；
- **示波器**：探头接地夹接 GND，逐个碰排针看波形；
- **一只 LED + 1 kΩ 电阻**：LED 长脚经电阻接排针、短脚接 GND，
  看闪烁快慢也能分辨（快的 = AB22）。

**按键**：官方引脚文件 `tang_mega_138K_pins.cst` 的 `====== Keys ======` 段里**只有两个键**：

| 按键 | 引脚 | 电平 |
|---|---|---|
| `Key_in[0]` | **AB13** | LVCMOS33 / 3.3 V / 内部上拉 |
| `Key_in[1]` | **Y12** | LVCMOS33 / 3.3 V / 内部上拉 |

板上丝印/位置的对应关系我没有实物，**请先跑 S1**：按哪个键 `led[1]` 亮，
哪个就是 AB13；按哪个键 `led[3:2]` 清零，哪个就是 Y12。
（如果按遍所有键都没反应，请把现象告诉 `liaison`。）

> ⚠️ `F4` 这个脚在别的例程里被当复位键用过，但它在 **1.5 V bank**，
> 和本设计其它所有 3.3 V 脚不同域，**本设计故意没用它**。

## 10. 故障速查

| 现象 | 最可能的原因 | 怎么办 |
|---|---|---|
| 灯闪一下又重来 / 跑到一半复位 | **单口 USB 供电掉电重启** | 双路 USB（USB3.0 + DEBUG-USB）或 12 V DC |
| 上电后什么都不亮 | 没长按 PWR 2 秒；或没烧进去 | 长按 PWR；重烧 S0 确认链路 |
| S0 的灯**完全不闪** | 时钟没跑 / 烧错器件版本 / 烧的是空码流 | 重新构建 S0 并核对构建输出里的 `PASS`；重烧 |
| S1 按键无反应 | 按的不是 AB13/Y12；或按键本身接触问题 | 见 §9；先跑 S0 确认板子活着 |
| S1 计数一次跳好几下 | 去抖窗口偏小 | 加大 `rtl/smoke/smoke_top.v` 里的 `DB_MAX` 并重建 |
| S2 没声音 | ① 耳机没插对孔 ② 烧的不是 S2 ③ 功放/供电问题 | 逐个排除；看 `led[1]` 是否亮 |
| S2 有声音但音高不对 | 采样率与频率字不匹配 | 本设计用 `BCK_DIV=1`（fs=97656.25 Hz）与 `tone_bank.v` 的频率字是配套的，别单独改其中一个 |
| S3 听不出包络（硬开硬关） | 烧的不是 S3 | 重烧 `smoke_top_s3.fs` |
| S4 音色不变 | 烧的不是 S4；或按的是同一个键 | 重烧；两个键都试试 |
| S5 数不出 32 根柱子 | `--fs` 填错 / 录音削波 / 导出成了 WAV / 烧成了单音级 | 见 §7.3 的五步排查 |
| 录音里有嗡嗡低频干扰 | 地环路 / 供电噪声 | 用电池供电的笔记本、或加隔离；麦克风录 |
| 某个打标脚测不到信号 | 认错脚了 | 跑 S0 按 §9 用频率认脚 |
