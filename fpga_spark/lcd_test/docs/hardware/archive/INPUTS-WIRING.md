# 整合固件接线与验收（`INPUTS_60K_*`）

> 当前位流：`INPUTS_60K_20261022-211920.fs`，User Code **`0x1A2B00B7`**
> 固件源：`hw_bringup/rtl/inputs_top.v`，约束：`hw_bringup/constr/hw_inputs.cst`
> 内容：当前固件覆盖 **13 键 + 6 光电遥测 + 2 只 ToF + 2 只 EC11**；
> PCB v1 已扩展到 **4 只 EC11**，新增两只需配合扩展 cst/RTL 验证。
> 已实测：13 键 ✅、光电 1 路 ✅、ToF A ✅、EC11 #1 ✅（其余路未接线）

---

## 1. 串口输出格式

每 ~40 ms 一行（60 字节，含 CRLF）：

```
K=1FFF P=3F A=037B B=FFFF E1=0000 E2=0000 S=F @000002CAAB
```

| 字段 | 含义 | 空闲值 | 触发时 |
|---|---|---|---|
| `K=` | 13 位键状态，bit n = 键 n | `1FFF` | 按下 → 对应位变 **0** |
| `P=` | 6 位光电状态，bit n = 光电 n | `3F` | 挡光 → 对应位变 **0** |
| `A=` | ToF #1 距离，毫米（十六进制） | 实测值 | 手移近 → 变小 |
| `B=` | ToF #2 距离 | `FFFF`（未接） | — |
| `E1=` | EC11 #1 累计计数，16 位有符号（补码） | `0000` | 正转增加、反转减少（每格 ±4） |
| `E2=` | EC11 #2 累计计数（当前位流未接入，PCB 规划） | `0000` | — |
| `S=` | **诊断字段**：4 位 = `A1 B1 A2 B2`（两路编码器的 A/B 原始电平） | `F` | 转动时在 `F/7/3/B` 之间变化 |

`A`/`B` 显示 `FFFF` = 那一路 I2C 没有应答。

## 3. 光电电平转换电路

下面记录的是面包板原型的 S9012 方案；自研 PCB v1 已改为 PC817，见
`PCB-SCHEMATIC-SPEC.md`。

E3F-20C1 的输出**不是纯开集**：内部还有一个约 **15.6 kΩ 上拉到自己的 +12V**，
所以黑线摆幅是 **0 V ↔ 12 V**，**直接接 FPGA 会烧 IO**。

用 **S9012（PNP）射极跟随器**：

```
              +3V3 (J8-1)
                │
              [10k]
                │
  黑线 ──[47k]──┼──── 发射极 E ────┬──── FPGA 输入（J13-16..21）
                │                  │
              [47k]          集电极 C ──── GND
                │
               GND
          （基极 B 接两个 47k 的中点）
```

**实测**：未遮挡 → 发射极 **3.3 V**（P 位=1）；遮挡 → **0.6 V**（P 位=0）。
0.6 V 低于 FPGA 的 VIL（0.8 V），可用；想留余量可把 10k 换 22k。

**元件（每路）**：S9012 ×1、47 kΩ ×2、10 kΩ ×1。

### 12 V 供电

1. 12 V 正极 → 所有发射器棕线 + 接收器棕线
2. 12 V 负极 → 所有发射器蓝线 + 接收器蓝线
3. 从同一个 0V 点**只拉一根线**到板子 GND

> 实测单套 E3F（接收+发送）约 20 mA，6 套约 120 mA；PC817 输入侧另约 50–60 mA。
> 12 V 总负载按 0.3 A 以上留余量即可。

## 4. ToF 接线（两只，各一条独立 I2C 总线）

| 总线 | 板子 SCL | 板子 SDA | 传感器 |
|---|---|---|---|
| A（**当前 S5 用，2026-10-24 起**） | **J13-24（A18）** | **J13-25（D15）** | 第 1 只（已接） |
| A（旧位置，仅 3.3 kHz 时可用） | ~~AB22（J8-10）~~ | ~~Y21（J8-11）~~ | — |
| B（PCB 规划） | **J13-29（F14）** | **J13-30（F13）** | 第 2 只（未接） |

总线 B 使用底板 `SDRAM0_EXIO0/EXIO1`，经 R68/R69 0 Ω 连到 `SDRAM0_DM0/DM1`；
接线前确认这两个 0 Ω 已安装。

每只都要：**SCL/SDA 各 4.7 kΩ 上拉到 3V3，各串 330 Ω**；3V3→红，GND→黑。

- 两只都保留出厂地址 **0x52**，靠"各占一条总线"避免地址冲突
- 器件 ID 寄存器 `0x03` = **0x4A**
- 距离寄存器 **`0x00`=低字节、`0x01`=高字节（小端，mm）** —— 与规格书相反

> ⚠️ **2026-10-23 真机实测更正（S5 整合时发现）**：写指针 0x00 后**连续读 2 字节**
> （自动递增突发读）时，**第一字节是高字节、第二字节才是低字节**——与上表的
> 单寄存器读顺序相反。证据：909 mm 的距离在突发读里到达顺序是 `03 8D`。
> 所以突发读的拼装是 `{第一字节, 第二字节}`，写反会得到 `8D03`（36099 mm）。
> `inputs_top.v` 的 `d_lo/d_hi` 捕获有 off-by-one，恰好与这个顺序抵消，
> 所以它当年读数看起来是对的——不要照抄它的捕获时序。

> ⚠️ **I2C 电气注意（2026-10-24，S5 实测）**：SCL/SDA 原来在 **AB22/Y21**（J8），
> 与音频 I2S（Y17/AB17/AA16）**同属 BANK7**。用 `DRIVE=8` + 10 kHz 轮询时，引脚翻转会把
> DAC 输出搅成尖锐噪声（音频完全不可用，与传感器是否供电无关）。
> **已验证的最终方案：把 I2C 挪到 J13-24(A18)/J13-25(D15)**（SDRAM0 组，远离音频）+
> `DRIVE=2`，**恢复到 10 kHz 依然完全干净**（位流 `MODE3_..._20261024-012557`）。
> 折中方案（不挪线）：留在 J8 但 `DRIVE=2` + `SCL ≤ 3.3 kHz` 也干净。
> 排查方法：`QUIET` 参数冻结 I2C/遥测后声音即恢复干净。

## 7. 故障对照表

| 现象 | 原因 |
|---|---|
| 完全没有 `K=` 行 | 调试串口没接对（P19 → USB-TTL RX，共地） |
| K 恒 `1FFF`，按键无效 | 键没接到对应 J13 脚 / 公共端没接 GND |
| K 某一位恒 0 | 该脚被短到 GND |
| P 恒 `3F`，挡光无反应 | S9012 电路没供电 / E、C 接反 / 黑线没接到 47k |
| P 恒 `00` | 光电输出一直 0V（12V、光束对准） |
| A 或 B = `FFFF` | 该路 I2C 不应答：4.7k 上拉缺失、SDA/SCL 接反、模块没供电 |
| `E1` 只在 ±1 抖动、不累加 | **A/B 只有一根在动** → 看 `S` 哪一位不变，检查那根线 |
| `S` 一直 `F` | A/B 都没信号（VCC 没接 / 线断） |
| `S` 乱跳（不转也跳） | 引脚浮空拾噪声（空脚正常现象） |
