# 交互硬件与 UI 映射

当前 UI 与硬件按同一张表设计，便于现场演示和后续 RTL 对齐。

## 钢琴

- 橡胶按键 `K1..K13`：C4..C5，按下 NoteOn，松开 NoteOff。
- 编码器 `E1`：力度。
- 编码器 `E2`：钢琴音色/击弦亮度。
- 编码器 `E3`：混响/空间量。

## 吉他

- 6 路光电 `S1..S6`：六根弦的拨弦/挡光触发，分别对应高音 E、B、G、D、A、低音 E。
- 橡胶按键 `K1..K13`：品位 0..12；按住某根弦时再按品位键，形成一个明确音符行为。
- 编码器 `E1`：拨弦力度。
- 编码器 `E2`：扫弦速度/起音速度。
- 编码器 `E3`：箱体明亮度；默认是木吉他干声，只有显式提高挂电强度才进入过载。
- UI 保留扫弦、上扫、下扫、拍弦、横按和 Capo 控件。

## 小提琴

- ToF：音调/把位，映射为四弦 G3-D4-A4-E5 上的音高位置。
- 红外输入暂不作为主音高源，保留给后续弓压/手势扩展，避免和 ToF 语义冲突。
- EC11（预留） 编码器 `E1`：本版不使用；音量由触屏/上位机 CC7 控制。
- 编码器 `E2`：颤音深度。
- 编码器 `E3`：弓位/亮度。
- UI 使用四弦指板和横向弓；保留滑音、颤音、颤弓和拨弦行为。

当前 UI 已先落地这张映射表；物理输入 RTL 后续按同名信号接入，避免 UI 与板上行为出现两套语义。
