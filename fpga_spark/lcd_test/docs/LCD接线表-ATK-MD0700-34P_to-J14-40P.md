# ATK-MD0700 34P -> Tang Mega 138K NEO Dock J14

适用：Tang Mega 138K NEO Dock 31005（GW5AST-138C）+ 正点原子 ATK-MD0700 V2.4（SSD1963，800x480，16-bit 8080）。

J14 是 SDRAM1/DVP_CAM/PMOD 复用接口。LCD 测试时不要同时使用 J8/J9 PMOD、DVP 摄像头或 SDRAM1 外设。LCD 数据位采用重排方式，以避开 GW5AST-138C 的 CPU/SSPI 专用球位；LCD 端必须严格按下表接线。

注意：正点原子手册规定 LCD P1-6 至 P1-21 依次为 D0 至 D15，P1-23 是 TE，不是 D15。

## J14丝印与编号方向

- 板上连接器位号丝印：`J14`。
- 下表中的 `J14-n` 表示 J14 排针的第 n 脚。
- 官方原理图中，J14 为 2×20 排针：奇数脚一列、偶数脚一列，从上到下依次为 `1/2、3/4、...、39/40`。J14-29/J14-30 还经过底板上的 0Ω 配置电阻，对应 FPGA 的 SDRAM1_DM0/DM1。
- 实物若只看见“J14”而看不清脚号，请先确认排针的 1 脚定位，再按上述排列数脚，不要仅凭左右方向猜测。

J14编号示意（按官方原理图排列）：

```
奇数列       偶数列
  1            2
  3            4
  5            6
  ...          ...
 39           40
```

## 安全注意

- P1-28 必须接 J14-11 的 5V，不能接 3.3V。
- 三个 LCD GND 必须并在一起接 J14-12。
- J14-34、36、38、40 已作为 LCD D4～D7 使用；不要把 J14-37 接线，J14-40 也不能接地。
- J14-22 对应 FPGA Y21，为 SSPI 专用球；本测试不使用 J14-22，LCD D2 必须接 J14-21（Y22）。
- 上电前检查 5V 与 GND 没有短路。
- 确认 J14 排针实物已经焊接。
