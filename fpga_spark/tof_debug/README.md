# Tang Mega 138K ToF 激光测距与 I2C 总线调试工程

> **工程目录**：`C:\Users\gjl50\Desktop\FPGA\fpga_spark\tof_debug`  
> **目标 FPGA**：高云半导体 Arora V 系列 `GW5AST-LV138PG484AC1/I0`（GW5AST-138C，Device Version C）  
> **设计目的**：参考 `fpga_hardware` 面包板与真板通信实测经验，针对当前 Tang Mega 138K 硬件架构提供一套轻量、敏捷、具备**7寸大屏直显 + 串口 ASCII 遥测 + I2C 全地址自动扫描**的专用 ToF 调试系统。

---

## 1. 核心调试功能

1. **双路 I2C 全地址自动扫描（I2C Bus Scan）**：
   - 遍历 112 个标准 I2C 7 位地址（`0x08` 至 `0x77`）；
   - 同时测试 **Bus 1**（`A18/D15`，排针 J13-24/25）与 **Bus 2**（`F14/F13`，排针 J13-29/30）；
   - 自动锁定并跟踪收到从机 ACK 的地址（自动兼容 VB22B 的 `0x52` 或 VL53L0X 的 `0x29` 等）；
   - 按板载按键 **Key0 (`AB13`)** 可随时命令 FPGA 重新执行全总线扫描。
2. **7 英寸 800×480 大屏直显（ATK-MD0700 / SSD1963）**：
   - **大号距离读数**：实时显示 `xxxx mm`，手遮挡/靠近远离实时响应；
   - **动态彩色距离指示条**：随着距离（0~1000 mm）平滑伸缩变色；
   - **双总线状态卡片**：显示当前激活总线、实时引脚电平（SCL=1/0, SDA=1/0）、器件 ID（`0x4A`）、通信成功率；
   - **16×8 I2C 地址矩阵表**：扫描到响应的设备地址以绿色高亮直观呈现。
3. **串口实时遥测输出（UART TX 115200 8N1，引脚 U15 / PC COM8）**：
   - 周期性输出纯文本 ASCII 报文：
     `[TOF] BUS=1 ADDR=0x52 ID=0x4A DIST= 245 mm ACK=1540 NACK=0 S1=1,1 S2=1,1`
   - 提供 Python 彩色动态控制台监控脚本 `tof_monitor.py`。
4. **板载 4-LED 极简指示**：
   - `LED[0]` (T18)：1 Hz 心跳闪烁（系统运行正常）；
   - `LED[1]` (R18)：I2C 轮询翻转闪烁；
   - `LED[2]` (R17)：收到有效从机 ACK 时常亮；
   - `LED[3]` (P16)：测距在 100~800 mm 正常范围时点亮。

## 2. 硬件接线表（J13 扩展排针）

| 信号名称 | J13 排针脚号 | FPGA 球号 | 对应功能与说明 |
|:---|:---:|:---:|:---|
| **SCL1** | **Pin 24** | `A18` | ToF #1 I2C 时钟线（板载 4.7 kΩ 上拉到 3.3V + 330Ω 串阻） |
| **SDA1** | **Pin 25** | `D15` | ToF #1 I2C 数据线（板载 4.7 kΩ 上拉到 3.3V + 330Ω 串阻） |
| **SCL2** | **Pin 29** | `F14` | ToF #2 I2C 时钟线（经底板 R68 0Ω，板载 4.7 kΩ 上拉） |
| **SDA2** | **Pin 30** | `F13` | ToF #2 I2C 数据线（经底板 R70 0Ω，板载 4.7 kΩ 上拉） |
| **+3.3V** | J8-1/2 或 J9-1/2 | 3.3V | 传感器供电正极（⚠️ 严禁接 5V） |
| **GND** | **Pin 12** | GND | 逻辑地（必须与开发板共地） |

## 3. 快速编译与运行步骤

### 3.1 一键构建（约 15~20 秒）
打开终端进入本工程目录，运行：
```powershell
python build.py
```
脚本将自动调用 `gw_sh.exe` 完成轻量综合与布局布线，在 `bitstream/` 目录下生成 `tof_debug.fs`。

### 3.2 一键在线烧录至 SRAM
```powershell
python burn.py
```
烧录完成约 26 秒，终端提示 `[OK] SRAM 下载完成` 后，开发板 LED 开始闪烁，7 寸大屏与串口立即输出数据。

### 3.3 运行 PC 串口监视器
```powershell
python tof_monitor.py
```
即可在终端看到彩色的实时距离进度条与总线状态。
