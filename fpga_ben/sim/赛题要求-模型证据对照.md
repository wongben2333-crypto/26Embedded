## 一、基础要求（3 项，缺一不可）

| # | 要求 | 模型证据 | 判定 |
|---|---|---|---|
| 基础① | 自研交互，**≥2 个独立可控演奏维度**（选音/触发/拨弦/力度） | 模型侧只有 `velocity` 参数与 MIDI 音符输入（`allocator.py`），**无任何传感器采集**；力度映射在 `voice.py`/`realtime_demo.py` 可实现 | ❌ **未做**（属硬件交互子系统） |
| 基础② | **纯 HDL** 逐样本实时合成，控制→发声 **≤10ms** | 逐样本合成已验证；延迟预算 `latency.py`：**48k 0.354ms / 96k 0.177ms**；`out\report.md` 第 7 节 | ⚠️ **算法侧达标**（延迟预算 ✅）；"纯 HDL" 需 RTL 落地（另见 `fpga_spark`） |
| 基础③ | 复音 **≥4**、ADSR、单音**实时变调**、多声部混音、**严禁预录 PCM** | `poly4.wav`（active=4）；`adsr.png`（peak1.0/sustain0.70/tail0）；`verify_targeted.py [2]` 实时变调 880.0Hz 连续无跳变；`mixer.py` 无溢出；全模型逐样本合成、无 PCM 播放 | ✅ **达标** |

## 二、拓展要求（4 项）

| # | 要求 | 模型证据 | 判定 |
|---|---|---|---|
| 拓展① | 复音 **≥32** / 加法分量 ≥32 / 多物理建模单元 | `poly32.wav`（active=32）；`additive.py` 32 分量；`testmode` 32 声部 | ✅ **达标** |
| 拓展② | **≥3 维表情** + **≥2 音色** + 效果器（混响/延迟/合唱） | 音色：organ/musicbox/epiano（`verify_targeted [3]` 三个质心各异 1289/1093/716Hz）；效果器：`delay/chorus/reverb` 全部通过（`verify_targeted [4]`）；表情：**力度 ✅、实时变调/颤音 ✅**，滑音可扩展 | ⚠️ **部分达标**（音色+效果器 ✅；表情维度需再补 1 维） |
| 拓展③ | 延迟 **≤5ms 无抖动** + 可视化（LED/李萨如/频谱/波形） | 延迟：`latency.py` **96k 0.177ms**（≤5ms）；可视化：`testmode.plot_spectrum` 有频谱图，但**无 LED/李萨如/波形** | ⚠️ **延迟达标**；可视化 ❌ **未做** |
| 拓展④ | 脱机 LED 曲目指引 + 蓝牙 App 联动 | 无 | ❌ **未做** |

## 三、核心评分规则（3 条）

| # | 规则 | 模型证据 | 判定 |
|---|---|---|---|
| 规则① | 振荡器 = **独立相位累加器 + 频率调控 + 包络控制** | `voice.py` / `allocator.py`：每声部独立相位、独立频率字、独立 ADSR；`dds.phase_sequence` 返回步进前相位便于 RTL 对齐 | ✅ 结构符合 |
| 规则② | 吞吐量 = **活跃振荡器 × 实际采样率** | 32 声部 × 48k = **1.536 M**（或 96k = **3.07 M**）；资源估算 `resource_est.py`：**LUT 5.9% / DSP 10.7% / BSRAM 0.3%** | ✅ 有量化支撑 |
| 规则③ | 测试模式输出多路频率，频谱可见 **N 个独立谱峰** + RTL 佐证无预录 | `verify_targeted [1]`：**detected 32 / expected 32 → PASS**；独立复核 200–6400Hz、间隔 200.00Hz（σ0.12Hz）；`testmode_32peaks.png/.wav` | ✅ 达标（但 RTL 佐证需硬件侧配合） |

## 四、总结

| 层面 | 黄金模型覆盖情况 |
|---|---|
| **合成引擎内核**（DDS/波表/ADSR/复音/混音/效果器） | ✅ 完整、可复现、指标可量化 |
| **复音规模**（≥4 基础 / ≥32 拓展） | ✅ 均达标（含资源可行性） |
| **延迟** | ✅ 预算达标（≤10ms 与 ≤5ms 均满足） |
| **音色 / 效果器** | ✅ ≥2 音色 + 3 类效果器 |
| **交互采集（基础①）** | ❌ 未做（硬件子系统） |
| **可视化 / 脱机指引 / 蓝牙（拓展③④）** | ❌ 未做 |
| **纯 HDL 落地** | ❌ 需 RTL（另见 `fpga_spark` 侧评审） |

**一句话**：黄金模型把题目里**"算法与指标"**的部分基本吃透（合成内核 + 32 复音 + 延迟 + 测试模式谱峰），
**缺的是"系统与交互"**（传感器采集、可视化、联机）以及**纯 HDL 落地**。
