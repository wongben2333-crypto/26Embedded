# Tang Mega 138K 外设准备清单（初版）

> 配套图片：`TangMega138K-外设准备清单.png`（3200×8578）/ `...-轻量版.png`（1600×4289）
> 用途：2026 嵌赛 · 高云赛道 · 选题二「实时多音色合成电子乐器引擎」
> 基于 Sipeed 官方 Wiki 板载参数表 + 官方例程 + 开源工程实测经验整理

**核心结论：音频输出完全不用买**（板载 PT8211 DAC + 3.5mm 耳机口 + 2 路 3W 喇叭接口），真正要自己动手的是**演奏琴键**。

---

## 1. 板子自带什么（先盘清家底）

### 1.1 算力与存储 —— 完全够用
- **FPGA**：GW5AST-LV138PG484A —— **138,240 LUT / 138,240 FF**
- 片上存储：S-SRAM 1080 Kb + B-SRAM **6120 Kb（340 块）**
- 乘法器：**298 个 18×18** ｜ PLL ×12 ｜ 全局时钟 16
- **硬核 RISC-V：AE350 @800MHz**（可跑参数配置/UI，不跑合成算法）
- 内存：**1GiB DDR3**（512MiB × 2）｜ Flash 128/64Mbits
- **SD 卡槽 ×1**（SDIO/SPI，可做曲谱/录音存储）

> **对电子乐器的意义**：32 复音预估仅需 **~6K LUT + 32 DSP**，资源余量极大；DDR3 可做长延迟线 / 多效果器。

### 1.2 音频输出 —— ✅ 板载自带
- **板载音频 DAC：PT8211**（16-bit R-2R 梯形网络，**LSB-justified 格式，无 MCLK**）
- **3.5mm 耳机口 ×1**（立体声输出，无 Mic）
- **Speaker 接口 ×2**（支持 **2× 3W 扬声器**，可直接驱动喇叭）
- 参考引脚（以官方 pin constraint 为准）：
  - HP_BCK **Y17** ｜ HP_WS **AB17** ｜ HP_DIN **AA16** ｜ PA_EN **AB16（低电平使能功放）**

> ⚠️ **不要试图用 HDMI 传音频** —— 真 HDMI 音频需要 data island + TERC4 编码，纯 DVI 发射器做不到。

### 1.3 显示与可视化 —— 基本够用
- **DVI TX ×1**（HDMI 输出，**与 DVI RX 互相占用**，只能二选一）
- **RGB 接口 ×1**（支持 RGB888 屏幕）
- 板载 **8 个 PMOD LED** + 4 个电量指示灯
- **WS2812 ×1**（与 aRGB 灯带连接器同数据引脚，可外接灯带）

> **对电子乐器的意义**：频谱 / 李萨如 / 波形可走 HDMI；**LED 演奏指引可直接用板载 8 灯 + WS2812 灯带**。

### 1.4 交互输入 —— ⚠️ 严重不足，需扩展
- 板载按键仅 **3 个用户按键 + 1 个 reconfig 键** —— **做不了琴键**
- **PMOD ×2**（与上侧 40P 排针、DVP 接口**复用**）
- **40P 排针 ×2**（琴键接线主要走这里）
- **ADC ×2**（底板 2 路差分输入通道）—— 可直接做**力度（velocity）采样**，不用额外买 ADC 芯片

> **结论**：**演奏琴键必须自己扩展**（电容触摸电极 / 光电对管 / FSR / 轻触按键）。

---

## 2. 一句话结论

**音频通路（DAC + 功放 + 喇叭接口）板子全自带**，你只需要买一个 **3W 喇叭** 或 **耳机/有源音箱**，插上就能响——不用自己画 DAC 电路、不用买 I2S 功放模块、不用做 RC 低通。

真正需要你花心思的只有两件事：**① 演奏琴键（要自己设计制作）② 调试验证工具（尤其是能看频谱的设备，用来证明"32 个独立谱峰"）**。

参考预算：**基础配置约 200–300 元**（不含示波器/显示器），全配约 500–700 元。

## 5. 分阶段采购建议

### 第一批 · 立刻买（W1：9/16–9/22）"让板子先响起来" —— 约 150–250 元
**12V DC 电源（DC5521）** + **USB-C 数据线 ×2** + **3W 喇叭 或 耳机** + **杜邦线 + 面包板 + 洞洞板** + **1MΩ 电阻** + **覆铜板/铜箔** + **机械轻触按键（保底）** + **TF 卡** + **USB 声卡**。

→ 目标：本地可视化、蓝牙 App 联动等拓展项。

## 6. 避坑提醒（10 条）

1. **供电不足会导致启动失败**。三种可靠方案任选：① 12V DC（DC5521）② USB3.0 + USB-DEBUG 双 5V USB ③ 3.7V 锂电池（≥3.6V，持续放电 ≥600mA）。调试阶段强烈建议用 12V DC。
2. **不是拨开关开机** —— 要**长按 PWR 键 2 秒**切换开关机状态（PWR 键在 HDMI 接口旁边）。很多人第一次以为板子坏了。
3. **IDE 里器件必须选对**：芯片 **GW5AST-LV138PG484A**，封装 **PBG484A**，**Device Version: B/C**。选错会综合失败或行为异常。
4. **IO 电压必须 3.3V**。用 GPIO 排针与外部通信时，过高电压会**永久损坏** PCBA。接自制琴键/传感器前先确认电平。
5. **DVI TX 与 DVI RX 互相占用** —— 同一路物理接口只能当输出或输入，二选一。做可视化时用 TX（输出）。
6. **PMOD 与 40P 排针、DVP 接口复用** —— 用了 PMOD 就不能同时用与之复用的 40P 引脚。**规划琴键接线前必须先查官方 pin constraint / 原理图**，否则会打架。
7. **板载音频 DAC 是 PT8211，走 LSB-justified 格式（不是标准 I2S），且没有 MCLK**。写代码时别照搬标准 I2S 时序，否则会有杂音或无声。参考引脚 HP_BCK/HP_WS/HP_DIN（以官方约束文件为准）。
8. **不出声先查 PA_EN** —— 功放使能是**低电平有效**，必须驱动为 0 才响（参考引脚 AB16，以官方为准）。
9. **138K Dock 与 138K Pro Dock 不是同一块板**：Dock = PG484（4 收发器 / PMOD×2 / ADC×2 / Speaker×2）；Pro = FPG676（8 收发器 / PMOD×3 / MIPI CSI×2 / Speaker×1，需商用版 IDE + Lic）。**下单前务必确认型号**。
10. **不要用 HDMI 传音频** —— 真 HDMI 音频需要 data island + TERC4，纯 DVI 发射器做不到。音频一律走 **3.5mm 耳机口 / Speaker 接口**。
