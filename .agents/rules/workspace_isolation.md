# 团队文件协同与独立隔离原则 (Team Workspace Isolation Rule)

## 核心要求
1. **严格隔离，禁止混淆**：
   - 本项目为多人协作项目。严禁将**我的文件**与**队友的文件**混合存放在同一个子目录下（例如不能把 FPGA 硬件仿真激励与队友的 Python 算法黄金模型都混在同一个 `sim/` 根目录下）。
2. **两套独立工作区**：
   - 队友工作区（算法参考模型、赛题解析、选题文档）：由队友维护，严禁擅自修改、混入硬件临时文件或破坏其结构。
   - 个人硬件工作区（高云 FPGA RTL 源码、物理管脚约束、Gowin EDA 工程配置、硬件仿真与音频 Demo）：独立组织与维护。
3. **协同操作规范**：
   - 在 pull / push / git 提交或新建文件时，严格审查归属，确保各自的文件在各自的独立目录/模块内，互不干扰、互不覆盖。
