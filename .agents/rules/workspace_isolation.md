# 团队文件协同与绝对隔离原则 (Team Workspace Isolation Rule)

## 核心原则：严格物理隔离，禁止跨境修改

1. **唯一允许写入与修改的个人工程目录**：
   - **`fpga_spark/`** 以及用户当前活动工作区 **`c:\Users\gjl50\Desktop\嵌赛`**。
   - 所有新建工程、RTL 源码、引脚约束、编译构建、测试脚本、位流生成与辅助脚本**必须且只能**在此范围内创建和修改。

2. **队友工程目录绝对只读，严禁触碰**：
   - **`fpga_hank/`**：队友 Hank 的专属工作区，**绝对只读（READ-ONLY）**。严禁向其添加、修改、格式化或删除任何文件（包括各种临时脚本、构建文件和 IDE 工程）。
   - **`fpga_ben/`**：队友 Ben 的专属工作区，**绝对只读（READ-ONLY）**。
   - **`fpga_hardware/`**：团队共享硬件与 PCB 参考，**未经明确指令禁止修改**。

3. **引用与学习规则**：
   - 允许读取、分析和参考队友目录（如 `fpga_hank/`）中的代码和文档。
   - 如需使用队友的最新成果，**只能复制到 `fpga_spark/` 或 `嵌赛/` 中使用和适配**，绝不回写到队友目录。

4. **Git 提交审查**：
   - 在任何 git add / commit 操作前，必须核验 `git status`，确保变动范围仅限 `fpga_spark/`，绝不污染队友的工作区。
