# 团队文件协同与独立隔离原则 (Team Workspace Isolation Rule)

## 核心要求
1. **各自独立探索，非算法与硬件分工**：
   - 团队目前处于个人独立并行探索阶段，两位成员均可自主探索算法、HDL 硬件或全流程系统，并非“一人算法、一人硬件”的死板分工。
2. **两套独立工作区**：
   - `fpga_ben/`：队友 Ben (wongben2333) 的专属独立工作目录。队友所有的探索、仿真、硬件设计、文档及产物均在自己目录下自由进行。
   - `fpga_spark/`：Spark (ZE-spark) 的专属独立工作目录。所有的工程文件、RTL 源码、引脚约束、专用测试激励与音频 Demo 均在此目录下展开。
3. **严格物理隔离，禁止跨境修改**：
   - 严禁将自己的文件放入对方目录，也严禁修改对方目录下的代码或配置。
   - 在 pull / push / git 提交时，严格审查归属，确保各自的文件在各自的独立目录内，互不干扰、互不覆盖。
