## 一、示波器测量与端到端响应延迟分析（核心指标论证）

### 1. 测量原理与公式

> **核心论断**：  
> **单通道上升沿触发，直接读 +Width（正脉宽） = 含硬件消抖的端到端总延迟（ $\approx 2.01\text{ ms} \le 5\text{ ms}$ ）**

在数字与物理交互系统中，传统的“按键按下到产生声音”延迟测试通常需要双通道示波器并排对比两个信号的边沿，极易受不同探头延时或触发电平漂移的影响。本设计在 FPGA 硬件顶层设计了**硬件专用时序打标逻辑（Timing Marker Pipeline）**：

- **打标引脚分配**：
  - **`MARK_E2E_RAW`**（板载 PMOD0 `J9-5` / 扩展排针 `J13-32`，FPGA 球号 `R18` / `F16`）：
    - **上升沿（0 → 1）**：物理按键/光电触点首次发生机械接触跳变时刻（未消抖的原始物理信号生效瞬间）；
    - **下降沿（1 → 0）**：FPGA 经过二级同步、硬件消抖、通道分配、相位累加与乘法器包络运算，向 DAC 移位寄存器装载第一个非零有效音频采样点时刻。
    - **物理意义**：示波器 CH1 探头接此单引脚，上升沿触发，测量示波器测得的 **`+Width`（正脉冲宽度）即直接等于按键到出声的端到端完整物理延迟**。
  - **`MARK_SYNTH`**（板载 PMOD0 `J9-6` / 扩展排针 `J13-31`，FPGA 球号 `T18` / `E17`）：
    - 测量纯硬件数字合成逻辑流水线延迟（扣除消抖后的 DDS + ADSR 运算耗时），正脉宽实测为 **20 ns（2 个时钟周期）**。
  - **`MARK_IN_PULSE`** 与 **`MARK_OUT_PULSE`**（`J9-8` 与 `J9-7`）：
    - 分别在按键触发时刻与 DAC 发出音频时刻输出 $100\ \mu\text{s}$ 独立脉冲，供双通道示波器测试差分时差 $\Delta t$。

### 2. 端到端延迟链路逐级因果分解

从物理机械按键闭合到 PT8211 音频 DAC 模拟引脚输出波形，纯数字逻辑流水线耗时如下：

$$\Delta T_{\text{total}} = t_{\text{sync}} + t_{\text{debounce}} + t_{\text{alloc}} + t_{\text{dds\_env}} + t_{\text{tdm\_mix}} + t_{\text{dac\_buf}} \approx 2.01\text{ ms}$$

1. **亚稳态消除级 ($t_{\text{sync}} = 20\text{ ns}$)**：双级 D 触发器同步外部异步机械信号（100 MHz 时钟驱动，2 周期）；
2. **硬件数字滤波消抖级 ($t_{\text{debounce}} = 2.00\text{ ms}$)**：20 位递减计数器（200,000 周期），彻底滤除 16 次以内的微秒级机械弹性弹跳；
3. **复音声道动态分配 ($t_{\text{alloc}} = 10\text{ ns}$)**：组合逻辑优先级编码器单周期锁定空闲振荡器槽位；
4. **DDS 相位累加与波形查找 ($t_{\text{dds}} = 10\text{ ns}$)**：32 位高精度相位累加器前推进步进字；
5. **ADSR 物理包络乘法器流水线 ($t_{\text{env}} = 10\text{ ns}$)**：DSP 硬件乘法器完成波形与振幅包络调制；
6. **32路时分复用混音缓冲 ($t_{\text{tdm\_mix}} \le 10.24\ \mu\text{s}$)**：在 $f_s = 97.65625\text{ kHz}$ 采样时钟下，最长等待 1 个采样周期装入输出 FIFO；
7. **PT8211 串行移位与模拟建立 ($t_{\text{dac\_buf}} = 20\text{ ns}$)**。

**结论**：总耗时严格控制在 **$2.01\text{ ms}$**，远低于赛题指标上限 **$5.00\text{ ms}$**，系统留有高达 **$59.8\%$** 的时序安全裕量。
