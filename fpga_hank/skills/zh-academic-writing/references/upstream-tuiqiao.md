# 推敲（tuiqiao）—— 中文技术写作 skill 的核心规则

> **来源**：<https://github.com/TingYu1769/skills-tuiqiao>（MIT）
> `SKILL.md`（已抓全文）+ `README.md`
> **用途**：本作品技术文档的改稿依据。**去 AI 味、改用词、理行文、有文采。**

---

## 一、三条边界（**优先于所有规则**）

| 边界 | 要求 |
|---|---|
| **信息守恒** | 事实、数字、公式、符号、引用、术语、限定词、否定、条件、归因，**一个不增一个不减**；不补例子、不补数字、不替作者编经历或论断 |
| **语体不降级** | 正式、平实的现代书面语；**不加**"说白了""讲真""我觉得"，不加感叹号，不写反问 |
| **不造新口癖** | 同一替换词 **一页出现三次以上** 就换一种改法；**原稿没有的标点习惯，改稿也不引入** |

## 二、改稿五遍（**顺序不能颠倒**）

```
1. 锁定       列出不能动的东西（事实/数字/公式/术语/图表位置/标题层级）
2. 理行文     只读每段前两句，看论证串不串得起来；结构问题先改
3. 改用词与句法
4. 去口癖、改标点
5. 添文采     最后，且克制：一节一两处就够
```
**⇒ 结构不对，字句改得再细也要返工**

---

## 三、⭐ 口癖强信号（**我文档里要逐个查的**）

| 类 | 表现 | 改法 |
|---|---|---|
| **翻案腔** | 「不是 A，而是 B」「与其说……不如说」「说到底」 | 平说 |
| **复述式推论** | 「这意味着」「换言之」后句与前句**同义** | 删后句 |
| **句首评论语** | 「值得注意的是」「值得一提的是」 | 删（或只补一个回指词）|
| **段首连接词连用** | 「首先…其次…最后」「此外」连用 | 删或改中性"还""也" |
| **话题壳** | 「对于……来说」「从……的角度看」「在……方面」 | 删 |
| **空转领句** | 「主要包括以下几点：」 | 直接写内容 |
| **元话语** | 「接下来我们将介绍」「下面分析」 | 删 |
| **相邻句同构** | 连续几句同一句式 | 打散 |
| **概括盖掉具体** | 同段已有数字却写「显著提升」 | 用数字 |
| **拟人化喻体** | 「像一位永不疲倦的助手」 | 删 |
| **金句收尾 / 升华** | 段末或节末加一句格言式总结 | 删 |
| **越证据断言** | 「证明了」「彻底」「首次」「完美」 | 降级为「表明」「在本配置下」 |
| **模糊归因** | 「研究表明」而无引用 | 给引用或删 |

**⇒ 成片才改的（不要见一个改一个）**：
「可以」虚化、限定词叠用、顿号长串、引号造词、装饰性加粗、**黑话与工程腔（收口、兜底、落盘）**、短主语后单独加逗号

**⇒ 已被推翻、不能据此改的**：
句长不够参差、同一名词反复出现、被动和名词化本身、三项并列、问句和比喻本身

## 四、⭐ 用词与句法（**W 系列**）

| 编号 | 规则 | 例 |
|---|---|---|
| **W1** | 万能动词 + 抽象名词 **还原成动词** | 「进行重排序」→「重排」；「实现了提升」→「提升了」；「给出分数 $S=…$」 |
| **W2** | 「对应」「具有」「存在」「扮演……角色」换成**真实的关系** | 「一一对应」要数两边项数 |
| **W4** | 「被」默认去掉；「被称为」→「称为」 | |
| **W5/W7** | 删话题壳 | 「对于……来说」「从……角度看」「在……方面」 |
| **W6** | 「通过……使」会**吞掉主语** | 改「……使……」或点明主语 |
| **W8** | 句首「作为 X」的 X **必须就是主语** | |
| **W9** | 长前置定语**拆成后置小句** | |
| **W10** | 「这一 + 名词」→「这个」「这种」 | |
| **W11** | 不计数、不引入新对象的「一个」**删掉** | |
| **W12** | 硬造的「性」「化」「度」**改回形容词** | |
| **W16** | 「正是」「恰恰」「格外」「尤其」**先删掉念一遍** | |
| **W17** | 「便」「之」「其」「此」成堆时换白话 | |

## 五、⭐ 标点（**PN 系列，依据 GB/T 15834—2011**）

| 规则 | 要求 |
|---|---|
| **破折号** | 只用于正文里的**解释说明**，**不制造揭晓式停顿** |
| **冒号** | 只用在有停顿处，**一句之内不套用两个** |
| **分号** | 只用于：① 内部有逗号的并列分句 ② 冒号后的分项列举 ③（GB/T 允许）非并列多重复句第一层——**技术文里多半拆成两句更清楚** |
| **经验阈值** | **全文每千汉字超过一个分号，就逐个查用途** |
| **PN16** | ⭐ **短主语后面不单独加逗号**（「缓存，是用空间换时间的办法」✗）|
| **引号** | 不为强调而加 |
| **中英混排** | 中文与英文、数字之间加空格 |

## 六、⭐ 行文（**F 系列**）

| 编号 | 规则 |
|---|---|
| **F1/F5** | 开头**直接进入事实或有代价的问题**，不用「随着……的发展」铺垫；新概念**先例子，再定义，再形式化** |
| **F2** | 旧信息在句首，新信息在句尾；前一句结尾接成后一句开头 |
| **F3** | 一段之内**主语尽量不换** |
| **F4** | 一段一个议题，要点落在**前两句** |
| **F7** | ⭐ **枚举写进句子**，不预告「有三个观察」再排「第一、第二、第三」；递进用中性「还」「也」 |
| **F8** | 证据按判断分组；几个数字为什么不同，**理由必须来自原文** |
| **F9** | 段间靠复述上段末尾名词、一个真问题、一个总括指代来衔接；**删「接下来我们将介绍」式元话语**；「然而」「因此」留给看不出来的关系 |
| **F10** | ⭐ 节尾**给判断**（边界、代价、反直觉推论、留给下一节的问题），**不把各段挨个缩写一遍，不升华** |
| **F11** | 章节回指用括号，**紧跟它支撑的说法** |

## 七、文采（**T 系列**）

| 编号 | 做法 |
|---|---|
| **T1** | 让**动词承重** |
| **T2** | 往准里炼字：「影响」→ 真正发生的「拖慢」「掩盖」 |
| **T3** | 比喻只取一面、写明取哪一面、一个比喻用到底、**不当论据** |
| **T4** | 用**对照**成文 |
| **T5** | **长句装条件和机制，短句下判断** |
| **T6** | 四字格和文言**一次一个** |
| **T7** | 替读者说出反对意见再转折 |
| **T8** | 用条件圈住断言然后说死 |
| **T9** | **具体胜过**「层面、维度、范式」 |
| **T10** | 在**关键数字旁用一句短话停一下**，不新增论断 |

**⛔ 不要的"文采"**：抒情、拟人叙述、造势排比、强化副词、升华、拿比喻当论据、追求平仄、换说法求变化、卖关子、死喻黑话、四字格连排、用文言替代白话

## 八、验收清单（**9 条**）

```
1. 信息守恒：数字/公式/引用/术语/限定词/否定/归因逐一对过
2. 行文：只读每段前两句，论证串得起来；节尾给的是判断
3. 口癖：强信号逐项查过，命中处逐个看上下文
4. 标点：每个分号说得出用途；没新增破折号；短主语后无单独逗号；无为强调加的引号和加粗
5. 没造新口癖：替换词没在一页里扎堆
6. 保护清单：一个都没被误改
7. 朗读：不拗口，没有电报句，没有口语词，没有感叹
8. 用户约定：项目体例优先
```

## 九、⭐ 保护清单（**看着像毛病、其实不该改**）

最常误伤的：
```
下定义的「即」「称为」与术语首现加粗
同一术语一名到底（为避重复换词，读者会以为换了东西）
证据性限定（通常、可能、几乎、据……报告）
决定真假的「之一」、限制性定语、量词「存在」、计数和引入新对象的「一个」、消歧的「被」、实验条件「在……上」
已成术语的「性」「化」「度」
推理里的「因此」「所以」
真实顺序里的「首先」「第一」
纠正读者真会有的误解的「不是 A，而是 B」
带来新推论的「这意味着」
分号的正当用法
交代证据来源的主语和动词
段首加粗小标题
被动、名词化、长句、句内真排比、问句、比喻本身
交叉引用、章首导读、章末小结
引用的原文、轨迹、提示词、代码一律照录
```
