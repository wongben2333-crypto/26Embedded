## 三、⭐⭐ DEAI_GUIDE：中文学位论文去 AI 化指南（原文核心）

### 四条核心原则
| 原则 | 要求 |
|---|---|
| **1 语法保真优先** | ⛔ 不改公式/引用/标签；✅ 只改普通段落、章节标题、图表标题 |
| **2 零捏造** | ⛔ 不新增数据、指标、对比结论、实验设置、新断言、新贡献点、新引用 |
| **3 提高信息密度** | 每句须传递**可核查信息**；无法核查的断言标 `【待补证】` |
| **4 克制措辞** | 避免无证据的过度确定；推测性断言加限定；不夸大 |

### 五类 AI 痕迹 + 消除法

#### 类别 1：空话与口号
| ❌ AI 痕迹 | ✅ 拟人化 |
|---|---|
| 显著提升 | 将 MAE 降低了 X% |
| 全面系统 | 分析了 X、Y、Z 三方面 |
| 有效解决 | 相比基线提升 X% |
| 重要意义 | 使 X 任务成为可能 |
| 鲁棒性好 | 在噪声环境下保持准确 |
| 新颖方法 | 在 X 基础上引入 Y |

#### 类别 2：过度确定
| ❌ 绝对化 | ✅ 限定化 |
|---|---|
| 显而易见 | 实验结果表明 |
| 毫无疑问 | 可认为 / 据此推断 |
| 必然 | 在本文设置下倾向于 |
| 完全 | 在大多数情况下 |
| 毫无例外 | 在实验观察范围内 |
| 总是 | 在本文实验条件下一致 |
| 从不 | 极少观察到 |

#### 类别 3：机械排比
❌ "该方法**快速、准确、高效**。" ⇒ ✅ "该方法处理速度达 1000 样本/秒，准确率 95%。"

**句式排比检测（C2）**：**连续 3 句及以上开头模式相同（前 2–4 字相同）**
❌ "本文提出了A方法。本文设计了B模块。本文实现了C框架。"
✅ "A方法旨在解决X问题。在此基础上，B模块通过Y机制增强了性能。此外，C框架将上述组件集成为端到端系统。"

#### 类别 4：模糊量化
| ❌ | ✅ |
|---|---|
| 大量研究 | 三项近期研究 [1-3] |
| 多次实验 | 在 X、Y、Z 三个数据集上的实验 |
| 大幅提升 | 提升了 12% |
| 绝大多数 | 78% 的案例 |
| 显著优于 | 以 p<0.01 优于基线 |

#### 类别 5：模板引言
❌ "时间序列预测是一个具有重要应用价值的课题。"
✅ "时间序列预测在电网优化 [1]、能源管理 [2]、金融规划 [3] 中发挥关键作用。"
❌ "随着科技的飞速发展…"

#### 类别 5b：⭐ AI 填充连接词（**C1**）
| ❌ AI 填充词 | ✅ 替换 |
|---|---|
| 总之 | 删除，直接陈述结论 |
| 综上所述 | 删除或替换为具体逻辑推导 |
| 不可否认的是 | 删除 |
| **值得注意的是** | **删除**，把"值得注意"的内容直接作主句 |
| **需要指出的是** | **删除**，直接陈述要点 |
| 不难发现 | 删除，让读者从数据自行判断 |
| 众所周知 | 删除或引用具体文献支撑 |
| 毋庸讳言 | 删除 |

**检测法**：这些词通常在句首，是 AI 高频特征。**删除后句子应仍完整。**

#### 类别 6：⭐ 堆叠式并列引用（**引言 / 文献综述**）
❌ "许多学者对此进行了研究 [1],[2],[3],[4],[5]。"
✅ "Smith 等人 [1] 提出了 X 方法，在 A 场景下取得了 Y 效果。Jones [2] 在此基础上引入了 Z 机制，但受限于 B。Wang 等人 [3] 则从 C 角度出发，解决了 D 问题。"

**规则**：
- **同一句并列引用不超过 2 个**（公认事实的背景陈述除外）
- **每篇被引文献至少附一句**对其核心贡献、方法或局限的描述
- 优先**叙述性引用**，而非括号堆砌
- 文献综述**按方法/范式分组**，组内逐篇讨论技术差异

## 四、分章节准则（原文）

### 摘要
**结构：目的 → 方法 → 关键结果（带数字）→ 结论**
| ❌ | ✅ |
|---|---|
| 本文提出了一种**新颖**的时间序列预测方法。| 本文提出了一种**基于注意力机制**的时间序列预测方法。|
| 实验结果表明，该方法取得了**显著的性能提升**。| 在 X 数据集上，该方法相比基线将 **MAE 降低了 12%**。|
| 本研究具有**重要的理论意义和应用价值**。| 该方法**使实时预测成为可能，延迟低于 10ms**。|

### 引言
**结构：重要性 → 空白 → 贡献 → 组织结构**
- ❌ "时间序列预测在现代社会中具有重要的地位。"
  ✅ "时间序列预测是电网优化 [1] 和供应链管理 [2] 的关键技术。"
- ❌ "然而，现有方法存在一定的局限性。"
  ✅ "然而，现有方法在噪声环境下无法有效捕获长程依赖 [2, 3]。"
- **贡献陈述规则**：每项贡献必须可核查；避免无证据的"首次""领先""最先进"；**陈述做了什么，而非强调多重要**

### 相关工作
**结构：分类 → 对比 → 定位**
- ❌ "Smith 等人提出了一种方法，效果很好。"
  ✅ "Smith 等人 [1] 提出了 X 方法，在 Z 数据集上达到 Y 准确率。"
- ❌ "我们的方法与他们的方法不同。"
  ✅ "与 [1, 2] 不同，本文方法引入注意力机制以…"
- **准则**：按方法/范式分组（非时间顺序）；对比具体技术差异；避免模糊赞扬

### 方法
**结构：概述 → 详细设计 → 算法 → 复杂度**
- ❌ "我们使用了一个神经网络。它非常强大。" ⇒ ✅ "我们使用了一个 3 层 LSTM，隐藏单元数为 256。"
- ❌ "算法收敛很快。" ⇒ ✅ "算法在 100 轮迭代内收敛。"
- **准则**：提供实现细节以保障可复现性；说明超参数与架构选择；效果放在结果章

### 实验
**结构：实验设置 → 数据集 → 评价指标 → 基线方法**
- ❌ "我们进行了大量的实验。" ⇒ ✅ "我们在 UCR 档案的 5 个数据集上进行了评估。"
- ❌ "我们和很多方法进行了对比。" ⇒ ✅ "我们与 4 个基线对比：ARIMA [1]、LSTM [2]、Transformer [3]、Informer [4]。"

### 结果
**结构：主要结果 → 消融实验 → 分析**
- ❌ "我们的方法比基线方法好很多。" ⇒ ✅ "相比最佳基线，本文方法将 MAE 降低了 12%。"
- ❌ "结果证明了我们方法的有效性。" ⇒ ✅ "表 1 显示，本文方法在 4/5 个数据集上取得最低 MAE。"
- **准则**：仅报告事实与数值；**不解释原因**（那是讨论章）；让表/图自己说话

### 讨论
**结构：结果解释 → 机制分析 → 局限性 → 未来工作**
- ❌ "我们的方法没有任何局限性。" ⇒ ✅ "本文方法训练时间更长（2.3 小时 vs 基线的 1.5 小时）。"
- **准则**：解释机制而非重述结果；**承认失败与边界条件**；诚实陈述局限

### 结论
**结构：总结 → 回答研究问题 → 未来工作**
- **准则**：直接回答研究问题；不引入新结果或断言；不提出新实验；未来工作具体可执行

## 五、⭐ 交付协议与改动类型（原文）

### 输出格式
```latex
% ============================================================
% 去AI化编辑（第X行 - [章节名称]）
% ============================================================
% 原文：[AI 痕迹文本]
% 修改后：[拟人化文本]
%
% 改动说明：
% 1. [改动类型]：[具体说明]
%
% ⚠️ 【待补证：需要证据支撑的断言】
% ============================================================
```

### 8 种改动类型
```
1 删除空话   2 补充具体   3 拆分长句（>50 字）  4 调整结构
5 降级措辞   6 删除冗余   7 补充主语            8 替换模板
```

### ⭐ 全库统一输出协议（`academic-writing-skills` 通用）
```latex
% <MODULE> (Line <N>) [Severity: Critical|Major|Minor] [Priority: P0|P1|P2]: <Issue summary>
% Before: <original>
% After:  <suggested>
% Rationale: <brief explanation>
% ⚠️ [PENDING VERIFICATION]: <if evidence/metric is required>
```
| Severity | 含义 |
|---|---|
| **Critical** | 阻塞投稿（编译失败、未定义引用、缺必需章节）|
| **Major** | 显著影响质量（语法错误、逻辑断裂、格式不合规）|
| **Minor** | 润色级（用词、风格一致性）|

### ⭐ AI 痕迹密度评分
| 得分 | 行动 |
|---|---|
| >70% | 紧急：立即重写 |
| 50–70% | 高：尽快重写 |
| 30–50% | 中：审查并修订 |
| <30% | 低：轻微润色即可 |

### 检测清单
**高优先级（必须修复）**：无具体信息的形容词（显著/全面/有效/重要）｜绝对化断言（显而易见/必然/完全/毫无疑问）｜模糊量化词（大量/众多/大幅/绝大多数）｜模板化表达（近年来/越来越多的/发挥重要作用）｜堆叠引用（同句 ≥3 引用无逐篇分析）

**中优先级（应当修复）**：无实质内容的三段式并列｜通用开头｜过度自信的预测｜无具体内容的三点列举

**低优先级（考虑修复）**：重复句式｜过度使用连接词｜被动语态

## 六、`paper-audit` 的分层审稿（原文）

| 层 | 检查 |
|---|---|
| L0 | 快速审计 / 门禁脚本 |
| L1 | 深审工作区准备（分节、摘要、主张映射）|
| L2 | 分节审稿泳道 |
| L3 | 跨节审稿泳道 |
| L4 | 汇总 + 引文核验 |
| L5 | 最终报告 + 修订路线图 + 可选评分 |

**四种模式**：`quick-audit`（快速筛查）｜`deep-review`（审稿人式批评）｜`gate`（只查阻塞项，PASS/FAIL）｜`re-audit`（修订验证）
**评分**：`ScholarEval` 8 维 1–10 分 + 可发表性标签；`NeurIPS` Quality/Clarity/Significance/Originality 1–6 分

## 七、⭐ AXES 段落连贯模型（README 提及，本项目已并入 skill）

段落需具备四要素：
```
A (Assertion)  主题句：本段主张
X (eXample/eXplain) 展开：机制或例证
E (Evidence)   证据：数据、引用、实验
S (Significance) 收束：对本章主线的作用
```
