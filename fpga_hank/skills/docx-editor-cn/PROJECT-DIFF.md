# 本项目规格 vs 上游 docx-editor-cn 规格（差异对照）

> **左列**：本项目从**三份往届获奖作品**实测得到（`技术文档-张杰-国一.pdf` / `技术报告-钟超炀-国二.pdf` / `技术文档-冯若陈-国二.pdf`，见 `_research/doc-format/FORMAT-SPEC.md`）
> **右列**：上游 `docx-editor-cn`（`REFERENCE.md`，面向中文课程论文/毕设/数模论文）
> **⇒ 两者都不是"标准"，是两个不同体裁的实测值。本项目按左列执行；右列用于补强能力。**

---

## 一、规格差异

| 项 | **本项目（往届获奖作品实测）** | 上游（中文学术通用） | 处理 |
|---|---|---|---|
| 纸张 | A4 | A4（11906×16838 DXA）| **一致** |
| 页边距 | **2.5 cm** | **2.5 cm**（1418 DXA）| **一致** |
| 页眉 | **无** | 未提 | 一致 |
| 页脚 | **`第 N 页共 M 页`** | `第 X 页 共 Y 页`（PAGE/TOTAL_PAGES 域）| **一致（用域）** |
| 正文字体 | **宋体 + Times New Roman** | 宋体 + **Cambria Math** | **用本项目的 Times New Roman** |
| 正文字号 | **12 pt（小四）** | **12 pt（小四）** | **一致** |
| 行距 | **1.5 倍（18 pt）** | **默认单倍**（`line:240`），备选 1.5 倍 | **用本项目的 1.5 倍** |
| 首行缩进 | 2 字符 | 2 字符（480 DXA）| **一致** |
| **一级标题** | **黑体 14 pt** | 黑体 **16 pt** | ⚠️ **不同** ⇒ 用本项目 14 pt |
| **二级标题** | **黑体 12 pt** | 黑体 **14 pt** | ⚠️ **不同** ⇒ 用本项目 12 pt |
| **三级标题** | **黑体 12 pt** | 黑体 **12 pt** | 一致 |
| **图/表题** | **黑体 10.5 pt** | **宋体 11 pt** | ⚠️ **不同**（字体与字号都不同）⇒ 用本项目 |
| **图号** | **章-序** `图 2.1` | **`图 1-1`（章-序，连字符）** | ⚠️ 分隔符不同 ⇒ 用本项目的 `图 2.1` |
| 图题位置 | 图**下** | 图**下** | 一致 |
| 表题位置 | 表**上** | 表**上** | 一致 |
| **表格样式** | `Table Grid`（全网格）| ⭐ **三线表**（顶/底 1.5pt + 表头线 0.75pt，无竖线）| ⭐ **本项目应改为三线表** |
| **公式布局** | 双制表位（CENTER 7.9cm + RIGHT 15.8cm）| 3 列无边框表格 [567｜7936｜567] | **两者皆可**；上游的需注意 `insideH/V` 也要 NONE、cell 要 `verticalAlign` |
| **公式载体** | Unicode 纯文本 | ⭐ **Word 原生 OMML**（temml→MathML→OMML）| ⭐ **本项目应升级** |
| **图表编号** | 手写 | ⭐ **Word SEQ 域**自动 | ⭐ **本项目可升级** |
| **参考文献** | GB/T 7714-2015 | GB/T 7714-2015（含 [J]/[M]/[D]/[C]/[EB/OL] 模板）| **一致**，可取上游模板 |
| **引用格式** | 上标数字 | `[n]` 上标 | 一致 |
| **章节名** | `第一部分 设计概述` | `一、引言`（H1 中文数字）| ⚠️ 不同体裁 ⇒ 用本项目 |
| **摘要/关键词页** | 三份往届中两份**没有** | 有 | ⇒ **本项目不加** |

## 二、上游**明确更强**的三处（本项目可升级）

### ⭐ 1. 公式：原生 Word 公式（本项目应为最高优先）
```
上游：LaTeX ──temml──► MathML ──mathml-to-docx──► Word OMML
本项目：LaTeX ──detex──► Unicode 纯文本          ✗ 不是真公式
```
> 上游原文明确：**never use plain `$$` LaTeX in the final docx**

**升级代价**：引入 Node.js + `docx` / `temml` / `fast-xml-parser`（或改用 pandoc ≥2.0 做 LaTeX→OMML）。

### ⭐ 2. 表格：三线表
```
顶线 1.5pt（size:12）｜表头下线 0.75pt（size:6）｜底线 1.5pt｜其余 NONE
⇒ 数据行所有边框设 NONE；表头不填色；表题无首行缩进
```
**升级代价**：低（python-docx 也能逐边设边框）。

### ⭐ 3. 编号：SEQ 域 / 自动编号
```
图表题：Word SEQ 域（figure_c1 / table_c1），改内容自动更新 ⇒ 不发散
标题  ：H1 中文数字写在文本里；H2/H3 用 per-chapter 自动编号
```
**⚠️ 上游的关键警告（本项目若做自动编号必看）**：
> **多级编号配置里绝不用 `LevelFormat.CHINESE_COUNTING`** —— `%1` 在 H2 里会展开成"二"，导致 `二.4` 而不是 `2.4`。
> 每一级都用 `LevelFormat.DECIMAL`。

## 三、上游列出的 11 个「生产中踩过的坑」（**本项目正踩 2 个**）

| # | 坑 | 上游解法 | 本项目状态 |
|---|---|---|---|
| **1** | 三线表中间横线可见 | 数据行 borders 全 `NONE` | 未用三线表 |
| **2** | 公式表格边框可见 | ⚠️ **`insideHorizontal`/`insideVertical` 也必须 `NONE`** | **未用表格法（无此坑）** |
| **3** | 标题编号不同步 | Word 自动编号 + per-chapter 引用 | 手写编号 ⇒ 会发散 |
| **4** | 标题里英文仍是宋体 | 字体用 `{ascii, eastAsia, hAnsi}` **对象形式** | ✅ 本项目已用对象形式 |
| **5** | 行间公式没用公式编辑器 | `temml` → `mathml-to-docx` | ✗ **本项目正踩** |
| **6** | 主标题英文宋体 | 标题字体混合配置 | ✅ 已处理 |
| **7** | 行内公式匹配过激 | 严格正则**排除纯数字与英文单词** | 本项目未做行内公式 |
| **8** | 引用未上标 | 检测 `[n]` 设 `superScript` | 未实现 |
| **10** | 缺分页符 | `pageBreak()`（**必须在 Paragraph 里**）| ✅ 已用分页 |
| **11** | ⚠️ 公式与编号不在同一基线 | 三个 cell 都加 `verticalAlign: CENTER` | **未用表格法（无此坑）** |

## 四、本项目**独有**的排版纪律（上游没有，来自本项目实测）

| # | 纪律 |
|---|---|
| **1** | **不要发明参考文档里没有的结构**：每章末「本章数据来源」表、摘要页、「赛题要求与章节对照」附录 —— **三份往届都没有**，一律删 |
| **2** | **删掉交代性前言**（「本节指标按测量场景分列：…」），直接写内容 |
| **3** | **评分相关话术只在「完成情况」一节出现**，其余位置不得出现"评分/分数/拓展/红线" |
| **4** | **图号必须机器校验**连续且唯一（多人并行写入曾产生两个"图 1.1"、图 3.5–3.8 逆序）|
| **5** | **指数写法全篇统一**（⛔ 不要同篇混用 `2^W` 与 `2¹⁷`）；减号统一 `−`；赋值不用 `←` |
| **6** | **含中文的 `.ps1` 必须 UTF-8 with BOM**；`.md`/`.v`/`.tcl` 无 BOM |
| **7** | **`Set-Content -Encoding UTF8` 在 PS 5.1 会加 BOM** ⇒ 用 `File.WriteAllText(..., UTF8Encoding($false))` |
| **8** | **`Get-Content` 按 GBK 解码 UTF-8 中文时吞换行** ⇒ 数行数必须用 .NET 或 Python |
| **9** | **图片在 Markdown 里必须写成 `![图 N.M 说明](路径)`**，写成加粗文字会导致 builder 插不进图 |
