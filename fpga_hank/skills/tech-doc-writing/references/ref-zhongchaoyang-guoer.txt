FPGA
作品名称：基于 的波束追踪系统
摘要
在无线电通信时代，用户对通信质量和覆盖范围的需求日益增长。5G技术
虽然具有高速率、低时延等优势，但由于其高频段信号（如毫米波）覆盖范围
有限，需要部署大量基站以实现连续覆盖，这不仅导致高昂的基建成本，还带
来巨大的能源消耗。在此背景下，可重构智能表面（RIS, Reconfigurable
Intelligent Surface）技术因其独特的优势成为突破现有通信瓶颈的潜在解决方
案。RIS 借鉴了相控阵的波束调控思想，其核心是由大量可编程的电磁单元
（如超表面元件）组成的平面结构，通过动态调节每个单元的电磁特性（如相
位、幅度、极化），实现对入射电磁波的智能反射或折射，从而优化信号传播
路径、增强目标区域信号强度或抑制干扰。
本作品面向单用户/多用户无规律移动终端，结合RIS技术，采用FPGA作
为可编程控制器件产生波束调控控制码，构建了移动终端电磁波追踪算法，实
现了一种基于 RIS 的波束追踪系统。
第一部分 作品概述
1.1 功能与特性
本作品面向单/多用户无规律移动终端，融合RIS技术与FPGA控制能力，
构建高效波束追踪系统。硬件上，基于变容管制作256单元可编程RIS，可通
过数/模控制实现多相位调控，反射幅度损失<3dB，工作频带 3.6GHz-
5.5GHz；创新用74HC595芯片高复用方案，16个FPGA引脚实现256单元独
立控制，经STA约束，相位更新指令2μs内同步到达，消除量化相位误差。 软
件算法上，FPGA实现两类追踪算法：单用户用贪婪子面算法，划分子面压缩
搜索复杂度至O(N/S)，实现子面毫秒级跟踪；多用户引入双阈值判决，双用户

1.3 主要技术特点
本系统的主要技术特点有：
1、硬件设计：高复用、高精度的 RIS 控制架构
可编程 RIS 硬件实现：采用 256 单元阵列设计，每个单元采用变容二极管
制作，通过数/模控制实现多相位调控，反射幅度损失均小于 3dB，工作频带覆
盖 3.6GHz-5.5GHz，满足 5G/6G 高频信号（毫米波）调控需求；单元采用两
层立体结构，优化调相层微带线宽度、长度及介质板厚度参数，降低各相位状
态间误差，确保波束赋形精度。
高复用率 FPGA 控制方案：基于 74HC595 串并转换芯片设计 16-256 路解
复用电路，通过分组控制策略与引脚复用技术，将 FPGA 单路物理引脚扩展为
16 路独立可控信号，仅需 16 个 FPGA 引脚即可实现 256 个 RIS 单元的独立
控制，大幅降低控制器引脚资源需求；RIS控制电路采用 FR-4 板材加工，集
成滤波、电压放大模块，满足 RIS 单元调控需求。

2、软件与算法：低复杂度、高适配的波束追踪机制
分层迭代的波束追踪算法：突破传统 “逐单元暴力搜索” 思路，单用户
场景下将 RIS 划分为空间相关子面，以 “单步调整—功率反馈—最优保留”
迭代策略压缩搜索空间，算法复杂度从 O (2^N) 降至 O (N/S)（S 为子面数
量），实现毫秒级波束跟踪；多用户场景在单用户的基础上引入 “最小接收功
率 + 平均接收功率” 双阈值判决，优先提升弱信号用户功率，同时优化用户
平均接收水平，双用户增益差 < 5.5dB，保障多用户公平性。
闭环反馈链路设计：构建由 adl5501 检波模块、RC 整流电路与分压模块组
成的有线反馈链路，将接收端喇叭天线的功率信号转换为 0-1V 直流电压信号，
通过 FPGA 的 XADC IP 核进行数据预处理，确保功率反馈数据平滑稳定，为
算法迭代提供实时、可靠的输入依据，避免因反馈波动导致的波束失锁。
时序约束保障：通过静态时序分析（STA）对时钟树、I/O 延迟与多周期路
径进行约束，将相位更新指令同步到达时间窗口控制在 2μs内，消除变容管开
关散布导致的量化相位误差，确保10s左右闭环周期稳定，保障移动场景下追
踪稳定性。
软件平台通信：基于 LabVIEW 与 USRP 搭建通信测试平台，实现信源编
码、OFDM调制、数据传输等完整通信流程，支持 4K 视频回传、RFID 信号
传输等场景。

1.5 主要创新点
本系统在设计和实现过程中，实现了多项创新，主要创新点包括：
1、利用FPGA的并行处理能力，实现低延迟的实时波束追踪系统，兼具高
效的系统处理效率与较低的资源利用率。
2、电磁波束追踪算法设计。突破传统“逐单元暴力搜索”或“行列分治”思
路，将RIS划分为空间相关子面，再以贪婪准则对子面执行“单步-反馈-保
留”迭代；既利用相邻单元信道高度相关特性压缩搜索空间（复杂度从
O(2^N)降到O(N/S)），又通过实时功率反馈保证收敛，实现快速、低算力的
多用户波束跟踪。针对多用户场景，在贪婪框架中引入“最小接收功率+平均
接收功率”双阈值判决，每轮迭代先标记功率最低用户，再以“提升最低值
以抬高均值”的思想更新子面相位。实验结果表面，该机制使双用户场景下
两个终端的接收功率实现提升与稳定。
3、算法加速设计。为便于算法快速运算，每个智能超表面单元，本文仅选取
“0”和“1”两种状态，使每个单元能够实现从逻辑“0”转变为逻辑“1”的转
变，实现了 180 度的相位差。当所有单元联合作用时，这些单元能够依据预
设的算法和指令对入射信号进行针对性的相位调制，使得反射信号按照特定
的方向和强度分布。
4、缩比验证测试系统构建。结合RIS 硬件和电磁波束追踪算法，通过电磁波
转换反馈链路辅助，以定向且位置可移动喇叭模拟移动用户终端，构建缩比
的 RIS波束追踪通信系统，从而进行硬件设计以及软件算法的可行性与有效
性进行验证。

1.74HC595解复用电路
由于所设计的控制模块与天线阵列息息相关，对于数字RIS 阵列，需要调
控其阵列中64个单元上的128个二极管；对于模拟RIS 阵列，需要独立调控其
阵列中256个单元上的256个变容二极管。可以看到，无论采用哪种方案，为
了能够独立控制每一个单元，需要使用 FPGA上的数百个引脚作为输出。
FPGA 引脚资源难以满足需求，因此需要利用外接电路，通过复用技术来拓展
FPGA 引脚口，从而解决引脚资源不足的问题。解复用部分的外接电路主要基
于 74HC595 芯片设计，一片单独的74HC595 芯片可以实现一路引脚到八路引
脚的复用。若直接使用该芯片，则可以降低 FPGA 的引脚需求，但是考虑到实
际中的 RIS 规模巨大，引脚需求要成千上万，因此一路转八路的设计并不能满
足实际应用的 RIS 阵列的引脚需求，因此为了实现更好的效果，需要进一步提
高引脚的利用率。考虑以下公式：
n=N/M (2-1)
其中n 表示 FPGA 需要作阵列控制信号的物理引脚，m 表示物理引脚复
用率，即一个物理引脚所复用成的逻辑引脚数量，N 表示天线阵列需要的引脚，
显然物理引脚复用率m越高，需要的 FPGA 物理引脚n 越少，当天线阵列需
要的引脚数量 N 为128，物理引脚复用率m为8，即1个物理引脚复用为 8 个
逻辑引脚时，所需的 FPGA 物理引脚n 为16个，进一步的，若提高物理引脚
26

=== PAGE 27 ===
复用率m至16，则需要的 FPGA物理引脚n 为8个，可见提高了 FPGA 引脚
的利用率，降低了 FPGA 的引脚需求。
当阵列所需引脚数很低时，不采用复用的结构要优于采用复用的结构，这
是因为采用复用时有固定的几路信号作为配置模块，增加了额外的开销，导致
最终需要的引脚数更多；但是随着阵列所需引脚数增加，不采用复用的结构中
FPGA 实际所需的引脚数要远大于采用复用时的引脚数，这是因为用作控制信
号输出的引脚所占比例开始增大，使得配置引脚可以开始忽略；同时随着复用
率越高，FPGA 所需的引脚数也会减少，带来的成本也在增加。
综合成本与引脚数来考虑，本项目采用的物理引脚复用率为16，即对于一
个 FPGA 的物理引脚，共输出 16 位的串行数据，输出的这些数据共负责控制
16 个天线阵列中的元件，如下图所示，左边的两个 74HC595 芯片 U2、U3 归
为一组，分别输出 16 位数据的前后 8 位，右边的两个74HC595 芯片 U4、U5
归为另一组，同样也是分别输出16 位数据的前后 8 位，每一组的两个芯片接
入同一个复用电路的物理引脚。四块芯片接入的 Vcc、GND、OE、SCK和
SCLR 引脚都相同，使得所有芯片的串行输入时序都相同，并保持同步。

2.低通滤波电路

3. 滤波分压电路
整流模块作为反馈链路的中间环节，采用了 RC 电路结构。该电路利用电阻 R
和电容C的特性协同工作，当 adl5501 检波模块输出的信号输入到 RC 整流电
路时，电容 C 在信号的正向周期进行充电，由于电容两端电压不能突变，在信
号的负向周期，电容通过电阻 R 缓慢放电，如此循环，实现对信号的整流功能
在这个过程中，电容C起到了平滑信号的关键作用，有效滤除信号中的高频纹
波，使输出信号更加稳定，降低了信号的波动幅度，为后续的分压模块提供了
一个相对平稳、纯净的直流信号。
分压模块则是有线反馈链路的末端关键组成部分，它基于欧姆定律和电阻分压
原理进行工作。在电路设计中，通过合理配置不同阻值的电阻，分压模块能够
对经过整流后的直流信号进行精确的分压处理，将信号幅度调整到合适的范围，
确保信号能够满足FPGA xadc 0-1v的电压输入范围。

该系统软件部分的核心目标是：实现一个高效、闭环的智能波束追踪控

整个软件系统可分为四大核心模块：算法控制模块、反馈处理模块、输
出控制模块和 通信传输模块。
一、算法控制模块：这是整个软件系统的智能核心，运行于 FPGA 上，
采用 Verilog语言编写。波束追踪算法核心为贪婪子面波束追踪算法，贪婪
算法具备适应性强的特性，由于在执行每一步决策过程中，仅需聚焦于当
前状态下的局部最优解，无需对整个复杂问题空间展开全方位的搜索与回
溯操作，这使得该算法的时间复杂度相对较低。此算法主要建立在两个核
心思想上：
1.空间相关性：在无线信道中，相邻的RIS单元其到达接收端的信道条件
非常相似。这意味着，无需独立调整每一个最小单元。若将相邻单元分组，
统一调整，可以大幅降低问题复杂度。由此，将256个RIS单元划分为16
个4x4的子面，每个子面都共享同一反射系数，这种设计使得在信号处理
过程中，能够以子面为单位进行更为高效的操作。
2.贪婪策略：不追求一步到位的全局最优解，而是每一步都追求“立即受
益”。通过一系列“只看眼前最优”的局部决策，逐步逼近全局较优解。
这种方法牺牲了理论上的绝对最优，换取了计算速度的极大提升，满足了
实时性要求。
算法主要分为下面几个步骤：
1.设定初始状态：给RIS一个初始配置，算法开始运行时，测得一个初始
接收功率P_max。
2.循环迭代过程：在对任何单元进行修改前，先将整个RIS的当前配置 R
完整地保存到一个临时变量 R_temp 中。这是为了万一试探失败，可以一
键还原。算法有一个指针，指向当前正在处理的“子面”的起始位置 (T_r
ow, T_col)，进入这个子面范围内的所有单元，将它们的相位状态统一切换
到另一种状态。使用这个新配置 R，通过反馈链路实时测量接收端的功率
36

=== PAGE 37 ===
P，随后进行功率比较，若P>P_max,说明这次集体翻转是有效的,于是更新
P_max = P，并将这个更优的配置 R 保存为 R_max;反之，则恢复上一次的
配置。通过控制子面的起始位置指针 (T_row, T_col) ，遍历所有的子面，
依次对每个“子面”的所有单元进行相位状态切换。
3.遍历所有子面，完成一轮优化，使波束主瓣精准指向用户。用户移动后，
此过程持续循环，实现实时追踪。
二、反馈处理模块：此模块负责将物理世界的信号强度转化为算法可以
理解的数字信息，是实现闭环控制 的关键。技术实现包括两步：1.信号预
处理：通过专门的功率值处理模对采集到的电压数据进行平滑滤波等处理，
消除波动，为算法提供稳定、可靠的实时接收功率值。2.信号采集：FPGA
通过其内置的 XADC IP核，读取从反馈链路传来的模拟电压信号；
三、输出控制模块：接收算法的决策，并直接驱动RIS硬件。核心组件
为串行转并行控制模块FPGA通过26个I/O引脚（16个用于数据，10个
用于控制）连接到外部的74HC595N芯片组。每个数据引脚与两片
74HC595N构成一个“1分16”的串转并子模块，从而高效地扩展出256路
独立的控制通道。其核心思想包括两部分：
1.通过引脚复用技术，将FPGA的一个物理引脚扩展为多个逻辑引脚，
实现多路独立控制。
2.采用分组控制策略，将多个控制单元分组，通过时序错开控制信号，
进一步提高复用效率。
其核心部分为：
1.数据传输模块：将数据生成模块的输出按低位到高位串行输出；每个
物理引脚对应一个数据传输模块实例，实现并行转串行。
2.芯片配置模块：控制74HC595芯片的使能端（OE）、时钟
（SCK）、寄存器时钟（RCK）；错开RCK上升沿，实现同一物理引
脚输出不同数据段（如前8位与后8位）。

2、单用户贪婪子面算法模块
传统RIS波束追踪算法采用每单元逐个调整的思想，理论上反射波束能
达到非常高的精度。但是当 RIS单元数量庞大，这种“暴力搜索”的方
式显示出弊端：遍历所有单元花费时间过长，不适应对实时性要求高的
通信系统；功耗消耗剧增；控制器消耗引脚数庞大等等。我们提出一种
贪婪子面算法，结合相邻子面信道相关的性质，将所有 RIS反射单元划
分为合理大小的子面，配合解复用电路，实现子面的反射角度统一控制。
子面大小由RIS反射单元总数确定，本项目采用4×4的子面（即每个子
面包含16个反射单元）。考虑到用户移动状态下对算法追踪速度的高要
求，我们对每个子面采取“0”和“1”的状态翻转控制思想，能够实现
180º的相位差，加速算法运算过程，也实现了波束的精确反射。用户接
收功率最高时，子面状态有唯一解，但是想求出唯一解十分困难。我们
采用了贪婪算法的思想，不追求一步到位的全局最优解，而是每一步都
追求功率的提升。通过一系列“功率提升”的局部决策，逐步逼近全局
较优解。这种方法牺牲了理论上的绝对最优，换取了计算速度的极大提
升，满足了实时性要求。
算法基于三段式状态机进行设计。接收到串口指令后开始进行变量初始
化，包括将变化（恢复）单元数量的计数器置零，把允许子面变化标志，
完成变化标志置零等等。通过反馈模块，接收当前 RIS配置下的接收功
率。按照初始配置（起始子面位置，RIS单元数量等），确定本轮算法
变化子面大小，更新变化索引，翻转当前索引的子面，生成九位控制占
空比的序列，通过74HC595芯片输出控制RIS子面翻转。
等待1s后输出稳定，通过反馈模块，接收子面翻转后RIS配置下的接收
功率，比较子面翻转前后的接收功率。若功率下降，则取消子面翻转，
恢复上一次的子面配置，执行下一轮的子面翻转算法；若功率上升，则
更新功率值用于下次比较，再执行下一轮子面翻转算法。

4、74HC595芯片配置模块
配置 74HC595 芯片的使能信号号一直为低电平，以保持正常工作
74HC595 芯片的串行输入时钟SCK的目的在于当74HC595芯片捕捉到
SCK 上升沿，串行数据由 SI输入到内部的8 位位移缓存器，并在缓存
器之间进行一次移位。因此 SCK 必须保持始终有效，才能使得
74HC595 芯片正常工作，考虑到74HC595 芯片内部从输入到输出存在
至少两个D触发器，若RCK与SCK保持上升沿的到来为同一时刻，则
输出信号不能稳定，故本模块对 SCK 处理为延后半个周期，即对
46

=== PAGE 47 ===
FPGA 的系统时钟进行一次反相操作再进行输出，这样能够保证当
74HC595芯片输入信号输入到第一个寄存器后，到输出触发器仍有半个
周期的时间，以满足触发器的建立时间、保持时间等，从而可以提高输
出的稳定性。
74HC595芯片的寄存器输出时钟 RCK的目的在于当 74HC595 芯片捕
捉到RCK 的上升沿，将在 8 位位移缓存器的数据存入到 8 位并行输出
缓存器，若此时使能信号有效，则同时将 8位数据进行并行输出。因此
为了完成能够完成复用率16的复用，将输出的两个RCK 信号进行上升
沿错位，使得数据传输模块完成前8位输出时，拉高其中一个RCK，当
数据传输模块完成后 8 位输出时，拉高另外一个 RCK。采用和数据传
输模块同步的计数器，计数范围同样为 0-15，当计数满8次，则拉高其
中一个RCK，当计数满16次，拉高另外一个RCK，然后RCK拉高后
都需再重新回到低电平，等待下一次的拉高。这样便可错开两个 RCK
上升沿，使得与 RCK1 相连的 74HC595 芯片和与 RCK2 相连的
74HC595芯片即使输入一样，但是输出能够做到相互独立。

5、PWM输出模块
在3.6GHz下，通过HFSS仿真得到相位和电容的对应关系。进一步，根据
变容管SMV1405-079LF的数据手册，可以其电容和电压之间的关系。推算可
得到RIS相位与电压之间的关系（见2.2.3 电路各模块介绍第一部分变容管反射
单元）。每一个占空比D都对应一个模拟电压V，因此采取控制占空比的形式
来控制输出电压，以此实现对RIS相位的配置，控制反射波束的角度。
通过实际测试，PWM 波输出的高电平约为4.5V，低电平接近为0V，输出
电压可表示为
Vout=4.5×D (2-2)
直接存储占空比数据不利于后续处理，因此将占空比再进行一定转换。
PWM 可以视为由一串 0 和一串 1 组成的数据流信号，其占空比也由以下式子
得到
D=n/N+M (2-3)
n 表示数据流中1的位数，m表示数据流中 0 的位数，若设定n+m=450，则
式(2-2)可变为：
Vout=n/100 (2-4)
此时对于分辨率为 0.01V 的每一档模拟电压Vout，都存在一个整数n使其成
立，而整数n可以直接简单存入数据生成模块中。数据生成模块负责存入对应
某模拟电压的整数 n，256 个单元因此需要存入 256 个整数 n，然后将 256 个
整数 n 传递至数据转换模块，数据转换模块则负责将整数 n 转换成对应占空比
50

=== PAGE 51 ===
的 PWM 波，以便后续输出并经过滤波转换为模拟电压。为方便与数据输出模
块对应，将 256 个整数 n 划分为 16 组，每组分别对应 16 个数据输出模块以
及 16 个 FPGA 输出引脚，每组 16 个整数 n 则分别对应 1 个 FPGA 输出引
脚负责的 16 个天线阵列单元。同时设定两个计数器，分别为占空比计数器和
位数计数 器，占空比计数器负责控制 0/1 的输出，而位数计数器负责确定 0/1
在串行输出的 16 位数据中的位数。
数据输出模块将整数 n 传递至数据转换模块，获取16 个整数 n，依次按顺序
取，通过与占空比计数器对比，若该整数比占空比计数器大，则代表对应
PWM 波还未达到设定的占空比，因此输出 1，否则输出 0，同时有一个位数
计数器，该计数器的值表示当前输出的 0/1 应赋值给 16 位数据中的哪一位，
当位数计
数器计满，表示当前占空比计数器已与 16 个整数 n 进行了一轮比较，此时占
空比计数器再进行计数，表示进行下一轮比较，当占空比计数器已经达到
450，表示 PWM波的所有位数都已确定完毕，输出16路完整的 PWM 波。
由于每一路 PWM 波信号对应的整数 n 与占空比计数器比较的时间不
同，因此各路 PWM 波之间会具有 1-15 个时钟周期的延迟，但是考虑到最后
是统一由芯片配置模块的 RCK 进行 74HC595 芯片的寄存器并行输出，因此
最终不会对实现阵列单元的控制造成影响。

7、串口控制模块
实现了参数化可配、时钟域独立、状态机精准、模块可拆、接口友好的串
口收发控制器IP。在可配置性方面，整套IP通过Verilog的参数化语法，将数

仅需在例化时修改参数，即可在相同板卡上配置各种模式的串口IP，无需改动
任何逻辑代码，极大提高了IP的重用范围。对于需要同时支持多种帧格式的多

=== PAGE 56 ===
栈开销。
在时钟域处理上，打破了传统 UART IP“单时钟”约束，收发两侧各自拥有独
立的时钟输入与异步复位。两个波特率控制器仅在各自时钟域内运行，数据发
送与接收模块的所有状态寄存器与数据路径也严格局限于本时钟域，跨时钟域
交互仅通过单比特“bps_start”脉冲及字节级valid/req握手信号完成，天然避免
多 bit 总线跨时钟问题。在协议处理精度上，设计引入了“双节拍”机制：
speed_select 模块为每一位生成两个关键脉冲：clk_bps_mid（位中间）与
clk_bps_stop（位结束）。接收引擎利用位中间脉冲采样数据线，最大限度抑制
抖动与线路噪声；发送引擎则提前数个时钟（clk_bps_stop_pre）准备下一位数
据，确保uart_tx在位边界处已稳定，避免输出毛刺。对于停止位，接收端除检
测高电平外，还在clk_bps_mid_post进行二次判决，杜绝因线路反射或采样偏
斜导致的帧错误。状态机划分清晰合理，所有跳转条件均与节拍脉冲严格对齐。

2、多用户贪婪子面算法模块
延续单用户贪婪子面算法的思想，当引入多用户时，核心矛盾是“资源

“最小功率保障 + 加权和速率优化” 双目标函数，同时实现 “弱用户
保护” 和 “总功率提升”。目标函数定义：

算法基于三段式状态机进行设计。接收到串口指令后开始进行变量初始

子面翻转。

取消子面翻转，恢复上一次的子面配置，执行下一轮的子面翻转算法；
若两者功率均上升，则更新功率值，并更新最小功率用户的功率值用于

最小功率用户的功率值，若上升则更新最小功率用户的功率值用于下次

次的子面配置。

第四部分 总结
4.1 可扩展之处
1、本作品仅使用一面 RIS 进行波束追踪研究，考虑到未来通信场景的复杂性
与多样化，后续将尝试引入多面 RIS 协同工作，探究其在不同通信环境下的性
能表现与应用潜力。
2、当前的波束追踪算法以动态自适应为主，后续将尝试引入神经网络架构，
让算法能够基于海量历史数据与实时反馈信息，自主学习并预测环境变化趋势，
进一步提升动态自适应的精准度与及时性。
3、当前仅聚焦于探究波束追踪功能，可探索与安全加密功能的有机结合，确保
在保障数据传输安全的基础上，进一步提升系统的整体可靠性。
4、控制模块部分虽然对如 FPGA 等的主控制器引脚需求大幅度下降，但是各
个电路之间仍然存在不少的连线，这对整个控制模块的稳定性造成了一定影响，
在后续工作中，可以将 FPGA、各个控制电路集成在一块电路上，提升整个控
制的稳定性。

1.设计效率提升
项目关键阶段耗时显著缩短，其中多用户算法架构设计周期从原计划 7 天

滤波电路设计中，根据截止频率给出可行的电路元件参数，无需额外查阅器件
手册，可以快速进行multisim仿真验证。
2.代码质量改善
LLM 针对74HC595 芯片配置模块提出的“时钟反相延迟”方案，解决了
RCK 与 SCK 上升沿冲突问题；提出使用独热码进行状态定义，避免状态机出
现错误跳转的可能性。发现代码中变量位宽的问题，提出正确的位宽，减少
debug时间成本。
3.学习效果
掌握了初步的时序约束技巧：通过 LLM 对 “约束过紧导致资源过载”
的案例分析，学会根据 FPGA 器件特性（XC7A35T 的 LUT/FF 资源上限）调
整约束强度，例如将非核心模块的建立时间裕量从 0.5ns 放宽至 1ns，在不影
响功能的前提下降低综合难度。针对 RIS 相位更新指令同步需求（2μs 内到达
所有单元），在 LLM 指导下掌握set_max_delay约束的应用，明确 “时钟树

延迟 + I/O 延迟” 的计算逻辑，通过 report_timing分析关键路径，优化路径
延迟，满足同步要求。
如何进行低功耗设计：通过 LLM 对 “PWM 输出模块频率与功耗关系”
的分析，将 PWM 波频率从 2kHz 调整为 1.72kHz，在满足滤波精度（电压波

IDLE 状态并触发复位信号，避免因硬件故障导致的状态卡死，提升系统稳定

重要交互1：多用户场景下的系统性能优化
用户问题：在单用户波束追踪系统验证成功后，如何将其有效扩展到多用户场

LLM建议：核心在于修改贪婪算法的决策目标。不能只追求总功率最大，而应
引入一个兼顾公平性与总性能的多目标函数。多用户场景下的性能优化需要突
破传统单目标优化的思维局限，建立兼顾效率与公平的系统级优化框架。核心
建议包括：
1.构建多目标联合优化函数：设计一个融合系统吞吐量与用户公平性的综合评
价指标，通过动态权重调节机制，平衡系统整体性能与个体用户体验。
2.引入智能资源分配策略：在波束成形算法中嵌入优先级自适应调整机制，实
时识别信道条件较差的弱势用户，在资源分配时给予适当倾斜，确保服务底线。
3.建立动态博弈决策体系：将多用户环境建模为非合作博弈场景，通过分布式
优化算法寻找纳什均衡点，实现系统资源的合理配置。

2.实现精细化的电压分辨率控制：采用高精度数字调制技术，通过增加控制位

4.添加运算放大电路提升电压范围：利用运算放大器的同相放大电路，将滤波

LLM建议：室内环境与户外LoS场景存在本质差异，其核心问题是多径效应
