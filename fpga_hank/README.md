> **2026 全国大学生嵌入式芯片与系统设计竞赛 · FPGA 创新设计赛道（高云半导体命题）**  
> **选题二：基于 FPGA 的实时多音色合成电子乐器引擎**  
> **硬件平台**：Sipeed Tang Mega 138K Dock ｜ **FPGA 芯片**：`GW5AST-LV138PG484AC1/I0`（Device: `GW5AST-138C`）  
> **显示与触控**：7 英寸 800×480 ATK-MD0700（SSD1963 16-bit 8080 并行总线 + GT911 电容多点触控）

## 1. 快速上手指南（3 分钟跑通）

### 1.1 环境要求
- **FPGA EDA**：高云 Gowin EDA V1.9.12.04（支持命令行 `gw_sh.exe` 与烧录器 `programmer_cli.exe`）
- **电脑端运行环境**：Python 3.8+（仅需 `pyserial`，用于串口交互与上位机 GUI）

### 1.2 电脑端运行步骤
```powershell
cd fpga_hank

# 1. 安装电脑端运行依赖（仅需 pyserial）
pip install -r host/requirements.txt

# 2. 启动电脑端演奏 GUI（将板卡 USB-DEBUG 连接至电脑）
python host/piano_gui.py
```
- 在界面上方下拉框选择端口（如 `COM9`），波特率默认 `115200`，点击 **「连接」**。
- 可直接用鼠标点击屏幕上的钢琴琴键，或按键盘白键（`A S D F G H J`）与黑键（`W E T Y U`）即时弹奏发声！
- 点击「大钢琴 / 原声吉他 / 擦弦提琴 / 民族二胡」即时切换音色，点击「旁路 / 延迟 / 合唱 / 混响」即时切换效果器。
- 界面会与 7 寸 LCD 屏实时双向同步（通过 MIDI `CC 28` 换页与 `CC 20` 换音色）。

### 1.3 一键编译与固化位流
```powershell
# 1. 一键命令行综合、布局布线与位流生成
& "F:\Gowin\Gowin_V1.9.12.04_x64\IDE\bin\gw_sh.exe" tools\gowin\build.tcl

# 2. 烧录到 SRAM 运行调试（操作码 2）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\gowin\program.ps1 -Mode sram -Fs out\bitstream\MODE3_freeplay.fs

# 3. 固化到位流 SPI Flash（操作码 68 thru GAO-Bridge，断电不丢失）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\gowin\program.ps1 -Mode flash -Fs out\bitstream\MODE3_freeplay.fs
```

> [!NOTE]
> **SPI Flash 烧录避坑纪律**：Tang Mega 138K Dock 的外部 SPI Flash 挂在 GAO-Bridge 之后，`programmer_cli` 必须使用操作码 68（`exFlash Erase,Program thru GAO-Bridge Arora V`），普通 op 9 会误报 `spi flash not found`。本项目 `program.ps1` 已全自动处理。

> [!WARNING]
> **避坑重要经验**：
> 1. J14-33（球号 `T20`）在 Tang Mega 138K 上为内部专用控制脚，如果连接会导致屏幕显示异常闪烁。本项目经硬件验证，触屏复位 `tp_rst_n` 必须分配至 **`W17`（J14-9）**。
> 2. GT911 I2C 通讯中，每次读完 6 字节坐标后，**必须向寄存器 `0x814E` 回写 `0x00`**，否则 GT911 内部 DSP 缓冲区死锁，导致后续触摸事件无法产生。

## 5. 电脑端控制软件与通讯协议

电脑端提供基于 Python `tkinter` + `pyserial` 构建的交互式虚拟钢琴软件（`host/piano_gui.py`）。该软件**仅负责 UI 交互与 MIDI 参数下发，不参与任何音频波形合成**，完全符合赛题规定。

### 5.1 串口参数
- **波特率**：`115200 bps`，`8` 位数据位，`1` 停止位，无校验（`8N1`）
- **物理接口**：Tang Mega 138K Dock 板载 USB-DEBUG（FT2232H 通道 B，识别为 `COM9`）

### 5.2 MIDI 协议控制规范

```
NoteOn : 0x90 note vel      (vel > 0 触发发声; vel == 0 视为 NoteOff)
NoteOff: 0x80 note vel      (释放对应音符进入 Release 阶段)
```

| 控制功能 | MIDI 指令 / CC | 取值范围 | 物理作用与映射规则 |
|---|---|---|---|
| **音色切换** | `CC 20` | `0..3` | `0`: 大钢琴 ｜ `1`: 原声吉他 ｜ `2`: 擦弦小提琴 ｜ `3`: 民族二胡 |
| **UI 页面切换** | `CC 28` | `0..3` | `0`: 演奏主页 ｜ `1`: 32谱峰 ｜ `2`: 乐曲播放 ｜ `3`: 声学延迟监控 |
| **效果器旁路** | `CC 21` | `0` 或 `127` | 旁路所有 DSP 效果器，输出干声基底 |
| **合唱使能** | `CC 22` | `0` 或 `127` | 开启多重延迟合唱（Chorus），增强声音厚度 |
| **延迟使能** | `CC 23` | `0` 或 `127` | 开启 350ms 立体声反馈回声（Delay/Echo） |
| **混响使能** | `CC 24` | `0` 或 `127` | 开启 Freeverb 算法硬件混响器（Reverb） |

## 6. 音频合成引擎与硬件效果器实现

### 6.1 32 复音 TDM 架构与 192 独立振荡器
- **时分复用（TDM）流水线**：利用 50 MHz 主时钟与 97.656 kHz 采样率之间的 512 个时钟周期裕量，在每个采样周期内，调度流水线完成 32 个复音声部的运算。
- **192 独立振荡器**：每个声部由 6 个带独立频率控制字、独立波表映射与独立幅度的加法振荡器构成（$32 \times 6 = 192$），充分满足赛题对独立发声单元的定义。
- **声部智能调度算法**：具备 Round-Robin 循环轮转与最老声部抢占（Voice Stealing）机制，即使演奏复杂和弦或快速琶音，依然平滑自然。

### 6.2 硬件数字音频效果器（DSP Effects）
- **Overdrive（非线性过载）**：多段多项式折线饱和限幅，提供真实的真空管放大器温暖破音。
- **4×12 箱体模拟（Cabinet Simulation）**：基于双二阶（Biquad IIR）滤波器的物理声学共振腔体建模，精确重现经典 Celestion V30 扬声器中低频冲击感。
- **Chorus（合唱器）**：低频正弦 LFO 调制 1024 样本环形 RAM 延迟指针，产生多重声部叠加感。
- **Echo / Delay（延迟器）**：32768 点硬件延迟流水线，具备衰减反馈环路。
- **Freeverb Reverb（混响器）**：4 组并联梳状滤波器（Comb Filter）+ 2 组串联全通滤波器（All-pass Filter），营造空灵开阔的殿堂声场。

## 8. 赛题红线与合规性审查指引（给评委）

针对全国大学生嵌入式竞赛专家评委的代码审查与合规性查验，系统提供以下确凿审查依据：

### 8.1 严禁播放预录 PCM / 整段录音触发审查
- **代码审查**：全面检查 `rtl/synth/` 与 `rtl/audio/`，系统中**没有任何音频采样 ROM**，没有任何 WAV 存储器，未挂载 SD 卡，未进行任何 PCM 推流。
- **算法属性**：所有声音均由相位累加器经过 DDS 正弦与傅里叶谐波加权实时生成，每个时钟周期按 $f_{out} = \frac{\Delta \Phi \times f_{clk}}{2^{32}}$ 逐样本计算。

### 8.2 严禁 CPU 承担音频合成算法审查
- Tang Mega 138K Dock 片上硬核 RISC-V CPU（AE350）在本项目中**完全处于旁路禁用状态**（未被实例化）。
- 整个音频生成链路从接收串口字节、解析 MIDI 消息、分配 32 声部、DDS 运算、ADSR 包络到数字混音和效果器处理，**100% 由纯 Verilog HDL 硬件状态机与专用乘加器流水线完成**。

### 8.3 32 独立振荡器与 32 谱峰必备交付物审查
- 运行 `MODE=2` 测试模式或在演奏界面打开 32 谱峰测试界面，系统输出 32 路互不重叠的独立音频基频（从 200 Hz 开始，每路间隔 200 Hz 直至 6400 Hz）。
- 将音频输出接入示波器或频谱仪，可清晰观察到 **32 根独立、等间距分布的清晰尖峰**，直接实证 32 个完整独立发声单元的真实并发能力。
