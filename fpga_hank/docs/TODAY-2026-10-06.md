## 2. 二胡"像小提琴"的攻坚（今日主线）

### 2.1 走过的弯路（**如实记录**）

| 轮 | 做了什么 | 结果 |
|---|---|---|
| 1 | 按"廉价二胡实测"做**固定低音区谐波权重表**（H1 弱 / H3 最强）| ⚠️ **高音区跟着错** ⇒ 用户听出"偏高" |
| 2 | 加 `drive`（持续激励，弓弦感）| ✅ **"有拉的感觉了"**（用户确认）|
| 3 | 加 **550 Hz 琴体曲线**（4 级 peaking biquad）| ✗ **滤波器按每时钟推进（应在采样率）⇒ 软膝触发 99.97%** ⇒ 已旁路 |
| 4 | 改按 **`sample_tick`** 门控 | ✗ **仍 99.17%** ⇒ 未定位，**放弃 RTL 滤波器路线** |
| 5 | 改走 **5 档谐波权重表**（`f(音高档, 泛音)`，装载期查表）| ✅ **0 违例、上板** ⇒ 但用户仍说"有些像小提琴" |
| 6 | 按**能量口径**重算 5 档表（α=0.65）+ 顺手修掉一个**错样本 bug** | ✅ 上板 |
| 7 | **H4 校准**（A4 的 1766 Hz 从 0.64 抬到 0.94）| ✅ **上板，待听感确认** |

### 2.2 ⭐⭐ 根因（**这是今天最重要的发现**）

> **用户给的原视频**：`BV1kXZ5BxEaT`【二胡】《赛马》独奏版（**已重新提取并验证与之前用的是同一段**：
> `cid=36057189401`，103 s，重提取 WAV 与旧 WAV **时长/采样数完全一致**）。

**三段独立录音交叉验证**（赛马 / 梁祝 / 弱水三千）后，得出：

| 发现 | 内容 |
|---|---|
| ⭐ **判别性特征在低频，不在 2–3 kHz** | **二胡在 `400–700 Hz` 有 `+23~+25 dB`（相对 1 kHz）的巨峰** ⇒ **1 kHz 反而是凹**；小提琴**没有**这么夸张的低频峰 |
| ⭐ **"像小提琴"的机理** | **一旦 400–700 Hz 不够突出 ⇒ 频谱变平 ⇒ 剩下的 1.5–3 kHz 抬高就显得像小提琴的「琴桥山」** |
| ⚠️ **2–3 kHz 不能用来区分** | 二胡 2–3 kHz 相对 1 kHz 是 **+4.1 dB**（1.8–3.2 kHz +9.3 dB）—— 与文献里小提琴的 0~+6 dB **量级接近** |
| ⚠️ **精确曲线不可跨录音复现** | 三段在 550 Hz 带给出 **+11.9 / +23.2 / +24.5 dB**（极差 **12.6 dB**）⇒ **不能把任何单段曲线写死给 RTL**，只能用**形状 + 可调系数** |
| ⚠️ **"2 kHz 以上极低"无法定论** | 三段 2–3 kHz 为 **−15.3 / −9.8 / −3.6 dB**，**排序恰好与码率同向**（132/159/176 kbps）⇒ **"编码削的"与"乐器本来就暗"都说得通**，**未能区分** |

**⭐ 可放心采用的三条（三段一致成立）**：

```
相对 1 kHz：
  315–700 Hz ：显著提升（+11.9~+25）⇒ 取中间 ~+18 dB
  ~1.6 kHz   ：次级抬高（+5~+13）  ⇒ ~+9 dB
  ~2.5 kHz   ：明确做凹（−9~−22）  ⇒ ~−12 dB
  3.5–5 kHz  ：继续降低（−13~−22）⇒ ~−15 dB
```

### 2.3 最终落地的 5 档谐波权重表（`BAND_MUL`，α=0.65 已含在内，**各档均值 = 1.000000**）

| 档 | f0 | H1 | H2 | H3 | H4 | H5 | H6 |
|---|---|---|---|---|---|---|---|
| 0 | **D4** 293.7 | 0.5430 | **2.2337** | 0.9270 | 0.9789 | 0.7491 | 0.5683 |
| 1 | **F4** 349.2 | 2.4182 | 1.2812 | 0.7595 | 0.8722 | 0.4957 | 0.1731 |
| 2 | **A4** 440.0 | **2.9624** | 0.9762 | 0.8605 | 0.9428 | 0.1488 | 0.1094 |
| 3 | **C5** 523.2 | 3.3609 | 1.1660 | 0.8982 | 0.2678 | 0.1348 | 0.1723 |
| 4 | **D5** 587.3 | 3.3586 | 1.2813 | 0.8546 | 0.1280 | 0.1918 | 0.1857 |

**验证（对照实测）**：
- **D4：H2 主导**（H2/H1 = +12.3 dB）✓ 实测 +18.9 dB（同向）
- **A4：H1 最强** ✓（实测：外弦 A4 基频最强）
- **A4/D5 的 H5/H6（2.2–2.6 kHz）压到 −26 / −29 dB** ✓（切掉小提琴的"琴桥山"区）
- **D4 的 H6（1762 Hz）未被压死** ✓
- **档 0 对低于 D4 的音是【外推，无实测支撑】**（已写进代码注释）

### 2.4 顺手修掉的一个**真 bug**（曾在板上发生）

```verilog
// 错：IIR 已旁路，但有效位延迟链被留下 ⇒ 二胡被推迟 6 个【采样点】
wire lim_vld = (inst_ok == 2'd2) ? fvld[5] : vld[4];
```
**后果**：**每个采样点读到的都是 6 个采样点之前的值** ⇒ 音频**错位**（发闷/叠影），
**不是良性延迟** ✗ ⇒ 已修为 `vld[4]` 并删掉 `fvld` 链 ✓

## 3. 证据与纪律（今天新增的经验）

### 3.1 ⭐ **口径陷阱的三种形态**（都用实测踩过）

| # | 形态 | 实例 |
|---|---|---|
| 1 | **占比 vs 相对电平** | 用"2–3 kHz 占总能量 0.42%" ⇒ 下"该滚降"（**错**，应按"相对 1 kHz 的每 Hz 电平"）|
| 2 | **整曲统计 vs 单音** | 用"整曲 1600–2000 Hz 占 3.7%"去定**单音**的 H4 |
| 3 | **不同基准的比值** | 用"琴体 1.6k/1k"去判断"**H4/H1**"（**两个不同量**）|

> **纪律**：**凡把两条曲线相比，必须先声明【两边各自的基准是什么】**；
> **"占总能量比例 / 相对某基准频带的每 Hz 电平 / 相对基频的谐波幅度"是三个不同的量，不可互换。**

### 3.2 其他今日教训

| 教训 | 来源 |
|---|---|
| **含中文的 `.ps1` 必须 UTF-8 with BOM**（否则 PS 5.1 按 GBK 读 ⇒ 字符串结构被破坏、解析崩）| 原子脚本 v1 失败 |
| **PowerShell 变量名大小写不敏感**：`$GEN`（路径）与 `$gen`（内容）**是同一个变量** ⇒ 路径被覆盖成文件内容 ⇒ "Illegal characters in path" | 原子脚本 v1 |
| **跨行正则 + 字符串重建**会截断字符串字面量 ⇒ **改用逐行编辑** | 原子脚本 v3 |
| **`Set-Content -Encoding UTF8` 在 PS 5.1 下会加 BOM** ⇒ `vlog` 报 `0xef 0xbb 0xbf`；应用 `[System.IO.File]::WriteAllText(..., UTF8Encoding($false))` | dump 第一次失败 |
| **1 GB 级目录存在时，"全仓递归搜索"当判据不可靠**（会被截断）⇒ 先限定到已知子树 | `liaison` 搜不到 TB |
| **TB 用固定文件名 + `"w"` 模式 ⇒ 跑第二个音高会静默覆盖第一个** | `liaison` 读 TB 源码发现 |
| **滤波器必须按采样率更新**（不是每时钟）—— 本项目**已犯两次** | 二胡 IIR |

## 6. 诚实说明（**边界**）

1. **"二胡像不像"最终判据是人耳** —— 本文档所有频谱数字都是**辅助**，不能替代听感 ✓
2. **三段参考录音全部是 AAC 有损**（131.9 / 158.8 / 176.3 kbps）⇒ **不是无损复核**；
   **"2 kHz 以上极低"是编码削的还是乐器本来就暗，未能区分** ⚠️
3. **《弱水三千》那段实测有伴奏**（`<280 Hz` 中位 4.79%，最强周期 86.8 Hz = F2，二胡拉不出来）
   ⇒ **该样本已作废** ⚠️
4. **三段乐器/麦克风/演奏者/曲风都不同** ⇒ **本就不是同条件重复实验** ⇒ 不一致可能是真实的乐器间差异 ⚠️
5. **CC0 小提琴实测未拿到**（四个源全失败）⇒ 小提琴侧的对比目前是**文献定性** ⚠️
6. **`<280 Hz` 判据只能排除"低音伴奏"**，排除不了"不占低频的伴奏" ⚠️
7. **H4 版尚未经听感确认** ⏳
8. **D4/A4 的引擎 dump 尚未产出**（正在跑）⏳
