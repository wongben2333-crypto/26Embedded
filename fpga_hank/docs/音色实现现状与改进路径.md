## 一、当前实现（**准确图景，含一处重要更正**）

### 1.1 音色切换是存在的 —— 信号名叫 `inst_sel`，不叫 `timbre`

```
piano_engine.v L169  input wire [1:0] inst_sel,   // 0=钢琴 1=电吉他 2/3=弓弦类
piano_engine.v L170  input wire [6:0] bow_speed,  // CC21 弓速（弓弦音色用，0 ⇒ 兜底中速 64）
piano_engine.v L216  wire [1:0] inst_ok = (inst_sel == 2'd1) ? 2'd1 :
                                          ((inst_sel == 2'd2) || (inst_sel == 2'd3)) ? 2'd2 : 2'd0;
piano_engine.v L219  piano_inst_lut u_inst_lut (.inst(inst_ok),
                                                 .ham_gain_q16(inst_ham_gain),
                                                 .ksh_ofs_enc (inst_ksh_enc));
top.v L373           .inst_sel (inst_sel_eff_r)
top.v L169           key1(AB13) 在【曲目模式】下 ⇒ 换乐器 0→1→2→3→0
```

> ⚠️ **`timbre_sel` / `timbre_user` 是另一条链**，只送 `tone_bank`（32 路测试音源，L393），
> **不控制演奏音色**。`top.v` L33-38 已实测确认：「MODE=1 下 key2 不会改变音色」。
> **看代码时不要把 `timbre_*` 和 `inst_sel` 混为一谈** —— 本项目已因此误判过一次。

### 1.2 三种音色的实现方式：**一个引擎 + 三张参数表**

| 要素 | 是否独立 | 实现位置 |
|---|---|---|
| 合成方法 | ❌ 全部是加法合成 | 统一 |
| 相位累加器 | ✅ 8 声部 × 6 泛音 = 48 个独立 | `piano_engine.v` |
| 谐波增益表 | ✅ 每音色一张（`ham_gain_q16`） | `piano_inst_lut` |
| 激励亮度 | ✅ 每音色一个偏移（`ksh_ofs_enc`） | 同上；L233 注释「拨片/指甲比毛毡琴槌亮 ⇒ lp_sh 更小」 |
| 包络/阻尼 | ✅ 每音色一组 | `piano_inst_lut` |
| 持续激励 | 仅弓弦类（`bow_speed > 0` ⇒ 不衰减） | `top.v` L345 `bow_speed_eff_r` |

### 1.3 钢琴这一路做得相当扎实（这是优势，不要动）

`piano_engine.v` 头部说明的设计依据是 **AMY 加法钢琴** + **Faust STK 击弦钢琴**，已实现：

- 非谐性 `f_n = n·f0·sqrt(1+B·n²)`，中音区 B≈0.0004
- 各泛音**独立包络**（高次先死）
- 力度 → 变亮（每泛音自己的 K[n] 系数，≈20 dB 相对提亮）
- 起音**宽带琴槌噪声**（"clunk"）
- 双弦失谐拍频（0.003 Hz 低音 → 1.0 Hz 高音）

**⇒ 钢琴是三种里最接近"像"的，问题不在钢琴。**

## 二、🔴 最大机会：**电吉他的失真链写完了，但没接进顶层**

### 2.1 事实

```
top.v 实例化的音频模块只有 5 个：
  song_player / piano_engine / tone_bank / adsr / audio_fx
  ❌ 没有 guitar_fx
  ❌ 没有 fx_dist
  ❌ 没有 cab_biquad（被 fx_dist/guitar_fx 内部引用）
```

而 `guitar_fx.v` **已经完成了**：

| 项 | 状态 |
|---|---|
| 模块本体 | ✅ 4.6 KB，端口齐（`fx_sel/cab_sel/drive/tone/level/fx_in/fx_out`） |
| 信号链 | ✅ 旁路 / [失真 4 相] → [箱体模拟 6 相] |
| 时序对策 | ✅ **10 级相位移位链**，只用 10 clk（200 ns），**不增加采样延迟** |
| Testbench | ✅ `sim/tb/tb_guitar_fx.v`（16.7 KB）+ `tb_guitar_probe.v` |
| 子模块 | ✅ `fx_dist.v`（过载/失真）+ `cab_biquad.v`（箱体）+ `cab_sim.v` |

**⇒ 也就是说：真电吉他的"听觉特征"（失真谐波 + 箱体共振）代码已经写好了，
只差在 `top.v` 里实例化 + 把 `inst_sel==1` 时把信号路由过去。**

### 2.2 预计效果

目前"电吉他"= 钢琴引擎 + 更亮的谐波表 + 更快的阻尼。
**没有失真、没有箱体 ⇒ 听起来必然像"拨弦钢琴"而不是电吉他。**

接上 `guitar_fx` 后，谐波结构会出现典型的**奇次谐波簇 + 箱体 2~4 kHz 共振峰**，
这是人耳判断"电吉他"的两个最关键线索。

## 三、二胡的缺口

现在：`bow_speed > 0` ⇒ 泛音**不衰减**（持续激励）。

**这是对的，但不够。** 二胡的辨识特征里，缺的是：

| 特征 | 现状 | 缺什么 |
|---|---|---|
| 持续激励 | ✅ `bow_speed` 门控不衰减 | — |
| **共振峰**（琴筒共鸣） | ❌ 无 | 需要 2~3 个带通（典型 ~500 Hz / ~1.5 kHz / ~3 kHz） |
| **揉弦**（压弦变音高） | ⚠️ 只有 `vib_*`（LFO 颤音） | 二胡揉弦是**音高**摆动，不是幅度颤音；如需可把 vib 改为调制频率字 |
| **滑音**（换把） | ✅ `glide_on/glide_time` | 基本够 |
| 摩擦噪声（弓毛） | ❌ 无 | 可复用琴槌噪声通道，改窄带 |

**性价比判断**：加 2~3 个固定系数的带通（一阶 IIR，资源极小）就能显著提升"像二胡"。
比改琴弦物理模型便宜得多。

## 四、还有一条硬约束：**声部数是 8，不是 32**

```
top.v L353  .N_VOICES (8),   // ★ 2026-10-06 曾试 20 ⇒ 时序失败(13203 违例/−6.774ns, BSRAM 219/340) 已回退
                             //   32 声部走 TDM 方案
```

- 8 声部 × 6 泛音 = **48 个独立加法分量** ⇒ 单音就满足拓展①「≥32 路」
- 但「复音 ≥32」这条**当前不成立**（20 都过不了时序）
- 32 声部只能走 **TDM 方案**，未实现

## 五、改进路径（按性价比排序）

### P0 · 接上 `guitar_fx`（**性价比最高**）

| 项 | 内容 |
|---|---|
| 改哪 | `top.v` 一处：实例化 `guitar_fx`，`inst_sel==1` 时把 `mix_piano` 路由过去 |
| 工作量 | 半天（接线 + 编译 + 上板听） |
| 风险 | ⚠️ **MODE=1 时序最差裕量只有 +0.009 ns** —— 但 `guitar_fx` 已用 10 级相位移位链专门规避，理论安全 |
| 验证 | 先跑 `tb_guitar_fx.v` 确认 PASS，再上板 A/B 对比 |
| 收益 | **电吉他音色从"拨弦钢琴"变成有失真和箱体**，直接兑现拓展②「≥2 种音色」 |

### P1 · 二胡加共振峰

加 2~3 个一阶带通（系数固定），串在二胡音色的输出上。工作量 1 天，资源可忽略。

### P2 · 揉弦改为调制音高

现在 `vib_*` 调的是**幅度**。二胡揉弦应该是**频率**摆动。改一处即可，但要重测质感。

### P3 · 32 声部 TDM

优先级最低（8 声部×6泛音已够拓展①的单音口径；32 复音是另一条）。
**且 20 声部已时序失败，32 风险极高**，8 天内不建议动。

## 六、⛔ 三件不要做的事

1. **不要动 `piano_engine.v` 的钢琴参数** —— 它已经是最好的那一路，改坏没收益
2. **不要为了「像」去加预录样本** —— 直接踩赛题红线（严禁预录 PCM），且会被 RTL 审查发现
3. **不要相信「多谐波 = 多振荡器」** —— 单波表查表只计 1 个振荡器，加分靠真复制实例，不是靠加泛音数
